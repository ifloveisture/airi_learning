# 学习路径 · 云端服务

## 目标

能本地起 Auth + API、分清认证 UI 与 OIDC 后端、知道计费（含 Capacitor）与 Admin 入口，并会用 ADR / API README 深挖。

| # | 读什么 |
|---|--------|
| 1 | [与通道边界](./与通道边界.md) — Auth / API / Channel 别混 |
| 2 | [本地启动](./本地启动.md) — compose、两进程 `.env.local` |
| 3 | [路由与能力](./路由与能力.md) + `server/apps/api/src/app.ts` |
| 4 | [认证与OIDC](./认证与OIDC.md) · [鉴权界面](./鉴权界面.md) |
| 5 | [计费与Flux](./计费与Flux.md) — Stripe + RevenueCat |

| 7 | [ai-context导读](./ai-context导读.md) — 改高风险链路前必读 ADR |

Chat 多端同步的 **Stage 侧 outbox/IDB** 在角色对话域；本路径只要求知道云端有 `/ws/chat`（见路由与能力）。

## 命令

```bash
pnpm dev:backend                              # DB/Redis + 常挂后端（compose）
pnpm -F @proj-airi/auth-server dev
pnpm -F @proj-airi/api-server dev
# 不是 pnpm dev:server（那是本机 Channel Hub）
# 不是 pnpm -F @proj-airi/server（旧单体已拆）
```
