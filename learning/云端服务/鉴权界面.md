# 鉴权界面

## 定位

`apps/ui-server-auth` 是独立 Vue/Vite **认证 SPA**（Cloudflare Pages）：登录、注册、邮箱验证、重置密码、个人资料、Electron OIDC 回调中继。不是 Stage 主应用。

## 真源

| 项 | 路径 |
|----|------|
| 说明 | `apps/ui-server-auth/README.md` |
| 入口 | `apps/ui-server-auth/src/main.ts` · `src/pages/*.vue` |
| API 基址 | `src/modules/auth-client.ts` / server-auth-context（`VITE_SERVER_URL` → **Auth** 原点） |
| 部署 | `wrangler.toml` · workflow `deploy-cloudflare-auth-ui.yml` |
| 后端 | `server/apps/auth`（Better Auth / OIDC），不是 `server/apps/api` 账本 |

旧「`apps/server` 历史重定向路由」若已删，以 Auth 与 SPA README 为准。

## 跟读

1. README
2. 页面路由与表单
3. 如何拼 `VITE_SERVER_URL`（指向 Auth）
4. 对照 [认证与OIDC](./认证与OIDC.md)：后端发 token，本 SPA 负责 UI

## 命令 / env

```bash
pnpm -F @proj-airi/ui-server-auth dev
# 或根脚本 pnpm dev:server-auth
# VITE_SERVER_URL=…  （本地 Auth 或 https://… 认证原点）
```

部署密钥名（CI）：`AUTH_CLOUDFLARE_ACCOUNT_ID` · `AUTH_CLOUDFLARE_API_TOKEN`

## 现状

已实现；CI 部署项目名约 `moeru-ai-airi-auth`。

## 边界

- **Stage Web/桌宠日常壳**：OIDC 客户端在 `stage-ui`，聊天主 UI 不在本 SPA。
- **Admin 控制台**：可能独立仓/面，不在本 app。
- **Better Auth API**：在 `server/apps/auth`，**不在**旧 `apps/server`。
