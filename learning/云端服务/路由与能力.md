# 路由与能力

## 装配

- 入口：`apps/server/src/app.ts`（Hono + injeca）
- 分层：`routes/`（校验鉴权）→ `services/`（业务）→ `schemas/`（Drizzle）
- 深读：`apps/server/docs/ai-context/architecture-overview.md`、`transport-and-routes.md`、`billing-architecture.md`

## 主要路由组

| 组 | 挂载 |
|----|------|
| Auth | `/` → UI + `/api/auth/*` + `/.well-known/*` + OIDC / Electron callback |
| Characters | `/api/v1/characters` |
| Providers | `/api/v1/providers` |
| Voice packs | `/api/v1/voice-packs` |
| Chats | `/api/v1/chats` |
| OpenAI 兼容 | `/api/v1/openai`；音频另见 `/api/v1/audio` |
| Flux | `/api/v1/flux` |
| Stripe | `/api/v1/stripe` |
| Chat WS | `GET /ws/chat?token=` |
| TTS WS | `GET /api/v1/audio/speech/ws` |
| STT stream | `POST /api/v1/audio/transcriptions/stream`（已实现；端侧 Official + Aliyun executor） |
| Admin | `/api/admin/*` + Admin UI |

栈：Better Auth、Drizzle/Postgres、Redis、Stripe。

## Auth（要点）

| 项 | 路径 / 事实 |
|----|-------------|
| 创建 | `apps/server/src/libs/auth`（`createAuth`） |
| 路由 | `routes/auth/` |
| 中间件 | `sessionMiddleware` 与 `authGuard`（401）分工不同；细读 ai-context |

前端登录壳：`apps/ui-server-auth`。

## Chat WS

| 层 | 路径 |
|----|------|
| 契约 | `packages/server-sdk-shared`：`chat:send-messages` / `pull` / `new-messages` |
| 服务 | `routes/chat-ws/`；跨实例常 Redis pub/sub |
| 客户端 | `stage-ui/libs/chat-sync` → [会话与云同步](../角色对话/会话与云同步.md) |

与插件通道 WS（`server-runtime`）**不是同一套**。

## 计费（高层）

- Flux 余额：billing 服务（Postgres 账本）
- Stripe：`routes/stripe/` + `services/domain/stripe`（checkout / webhook）
- LLM/TTS 网关：`routes/openai` 一带 billing middleware 扣费

深挖用包内 `billing-architecture.md`；learning 闭环见 [计费与Flux](./计费与Flux.md)。
