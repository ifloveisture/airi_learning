# 路由与能力

## 装配

云端拆成两套进程（见 [与通道边界](./与通道边界.md)）：

| 进程 | 入口 | 职责 |
|------|------|------|
| API | `server/apps/api/src/app.ts`（Hono + injeca） | 业务 REST、Chat/TTS WS、Flux、Stripe、RevenueCat、LLM 网关 |
| Auth | `server/apps/auth/src/server.ts` · `routes.ts` | Better Auth、OIDC、会话；**不**挂业务账本 |

API 分层：`routes/`（校验鉴权）→ `services/`（业务）→ `schemas/` + `drizzle/`（迁移真源在 API 包内）。

深读：`server/apps/api/README.md` · `server/docs/ai/adr/` · `server/AGENTS.md`。

## 主要路由组（API）

| 组 | 挂载 |
|----|------|
| Characters / cards | `/api/v1/characters` · character-cards 等 |
| Providers | `/api/v1/providers` |
| Voice packs · display models | `/api/v1/voice-packs` · display-models |
| Chats | `/api/v1/chats` |
| OpenAI 兼容 | `/api/v1/openai`；音频另见 `/api/v1/audio` |
| Flux | `/api/v1/flux` |
| Stripe | `/api/v1/stripe` |
| RevenueCat | `/api/v1/revenuecat`（webhook · sync · catalog · capacitors） |
| Chat WS | `GET /ws/chat?token=` |
| TTS WS | `GET /api/v1/audio/speech/ws` |
| STT stream | `POST /api/v1/audio/transcriptions/stream` |
| Admin | `/api/admin/*`（以源码挂载为准） |

栈：Hono、Drizzle/Postgres、Redis、Stripe、RevenueCat；Auth JWT 经 JWKS 校验。

## Auth（要点）

| 项 | 路径 / 事实 |
|----|-------------|
| 进程 | `server/apps/auth`（`@proj-airi/auth-server`） |
| OIDC / 会话边界 ADR | `server/docs/ai/adr/2026-09-20-oidc-jwt-session-boundary.md` |
| API 侧 | `sessionMiddleware` 填上下文；`authGuard` 401 |

前端登录壳：`apps/ui-server-auth`（打 Auth，不是打 API 账本）。

## Chat WS

| 层 | 路径 |
|----|------|
| 契约 | `server/packages/server-sdk-shared`（或 workspace 导出名以 package.json 为准） |
| 服务 | `server/apps/api/src/routes/chat-ws/`；跨实例常 Redis pub/sub |
| 客户端 | `stage-ui/libs/chat-sync` → [会话与云同步](../角色对话/会话与云同步.md) |

与插件通道 WS（`server-runtime`）**不是同一套**。

## 计费（高层）

- Flux 两桶：购买 Flux + Capacitor Flux（见 [计费与Flux](./计费与Flux.md)）
- Stripe：`routes/stripe/`
- RevenueCat：`routes/revenuecat/` → `syncCapacitor`
- LLM/TTS 网关：`routes/openai` 一带 billing middleware

## 相关包

| 包 | 角色 |
|----|------|
| `server/apps/api` drizzle | 云端业务库迁移真源 |
| `server/packages/auth-shared` | Auth 共享 schema 等 |
| `server/packages/server-sdk-shared` | Chat WS 等契约 |
| `server/packages/http-error-shared` | `ApiError` 统一错误 |
