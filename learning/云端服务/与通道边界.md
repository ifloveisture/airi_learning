# 与通道边界

## 一句话

**`apps/server` = 云端产品后端（账号 / 同步 / 计费 / LLM 网关）；`server-runtime` ↔ `server-sdk` = 本机模块事件总线。**

不要混称「那个 server」。

## 对照

| 维度 | 云端 `apps/server` | 模块 Channel |
|------|-------------------|--------------|
| 启动 | `pnpm -F @proj-airi/server dev` | 桌宠内嵌或 **`pnpm dev:server`** |
| 协议 | HTTP + Chat/TTS 等 WS | 模块 announce / 事件 WS |
| 客户端 | 浏览器、Stage chat-sync、OpenAI SDK 风格 | `server-sdk` Client、plugins、部分 services |
| 数据 | Postgres 等为账号/账本真源 | 进程间实时事件，不做云账号真源 |
| 包 | `server-schema`、`server-sdk-shared` | `plugin-protocol`、`server-shared`、`server-runtime`、`server-sdk` |

## 选题

| 需求 | 走哪 |
|------|------|
| 登录、跨设备聊天、Official 扣费 | **云端本域** |
| Discord / 浏览器扩展把上下文推进 Stage | **Channel**（协议在 `packages/plugin-protocol` + `server-sdk`；Hub 为 `server-runtime`） |
| 本机键鼠 / 终端自动化 | **MCP**（如 `services/computer-use-mcp`），不是 `apps/server` |

本页不展开 Channel/MCP 实现；只防止把三条总线写成一条。
