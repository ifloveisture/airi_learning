# 与通道边界

## 一句话

云端已拆成 **两套独立进程**（Auth + API）；本机 **Channel Hub**（`server-runtime`）是第三条栈。不要混称「那个 server」。

旧路径 `apps/server` / 包名 `@proj-airi/server` **已不存在**。跟读与命令一律用下表。

## 三套对照

| 维度 | Auth `server/apps/auth` | API `server/apps/api` | 模块 Channel |
|------|-------------------------|------------------------|--------------|
| 包名 | `@proj-airi/auth-server` | `@proj-airi/api-server` | `@proj-airi/server-runtime` 等 |
| 启动 | `pnpm -F @proj-airi/auth-server dev` | `pnpm -F @proj-airi/api-server dev` | 桌宠内嵌或 **`pnpm dev:server`** |
| 本地整栈 | `pnpm dev:backend`（`server/docker-compose.yaml`）常一起起 Auth + API + DB/Redis | 同左 | 不在 compose 业务面里 |
| 协议 | Better Auth · OIDC · 会话 | HTTP 业务 API + Chat/TTS WS | 模块 announce / 事件 WS |
| 客户端 | 认证 SPA、OIDC 拿 token | Stage chat-sync、Official 网关、订阅同步 | `server-sdk` Client、plugins |
| 数据 | 账号 / 会话（与 API 可共享 Postgres） | Flux 账本、聊天同步、网关计费 | 进程间事件，不做云账号真源 |
| 权威文档 | `server/apps/auth` + ADR | `server/apps/api/README.md` + `server/docs/ai/adr/` | plugin-protocol / server-sdk |

## 选题

| 需求 | 走哪 |
|------|------|
| 登录、OIDC、Electron 回调 | **Auth** |
| 跨设备聊天、Official 扣费、Stripe / RevenueCat | **API** |
| Discord / 浏览器扩展把上下文推进 Stage | **Channel** |
| 本机键鼠 / 终端自动化 | **MCP**（如 `services/computer-use-mcp`），不是云端 API |

本页不展开 Channel/MCP 实现；只防止把三条总线写成一条。
