# 本地启动

> 云端：**Auth** `@proj-airi/auth-server`（`server/apps/auth`）+ **API** `@proj-airi/api-server`（`server/apps/api`）。
> 整栈依赖：`pnpm dev:backend` → `server/docker-compose.yaml`。

## 定位

本地起账号与资源 API（同步、计费、OpenAI 兼容网关）。**不是**本机 Channel Hub（`pnpm dev:server` / `server-runtime`）。

旧命令 `pnpm -F @proj-airi/server` / 路径 `apps/server` **已失效**。

## 前置条件

缺任一项，对应进程会在 env 校验或连库处失败。

| # | 条件 | 说明 |
|---|------|------|
| 1 | 各 app 的 `.env.local` | API / Auth 各自 `dev` 脚本经 dotenvx 加载；以包内 README / `libs/env.ts` 为准 |
| 2 | 可连通的 Postgres | compose 默认映射见 `server/docker-compose.yaml`（常 `127.0.0.1:5435`） |
| 3 | 可连通的 Redis | compose 常 `127.0.0.1:6379` |
| 4 | Better Auth 密钥等 | 在 **Auth** 包 env |
| 5 | OAuth / OIDC 客户端 | Google / GitHub 等；以 Auth `env` schema 为准 |
| 6 | API 侧网关密钥等 | 如 LLM router 相关；以 API `env` 为准 |

真源：`server/apps/api/src/libs/env.ts` · `server/apps/auth/src/env.ts`（或同目录 Valibot schema）。

### 可选（不起服也可缺）

| 变量 / 能力 | 说明 |
|-------------|------|
| Stripe | `STRIPE_SECRET_KEY` · `STRIPE_WEBHOOK_SECRET` |
| RevenueCat | webhook auth/secret · environment；前端 Web Key |

## 命令

| 目的 | 命令 |
|------|------|
| 基础设施 + 常挂后端 | `pnpm dev:backend`（`docker compose -f server/docker-compose.yaml up --build`） |
| 仅 API | `pnpm -F @proj-airi/api-server dev` |
| 仅 Auth | `pnpm -F @proj-airi/auth-server dev` |
| API DB | `pnpm -F @proj-airi/api-server db:generate` / `db:push` |
| Auth schema | `pnpm -F @proj-airi/auth-server auth:generate`（写入 auth-shared 等，以脚本为准） |

密钥勿提交。细则见各 app `README` / `AGENTS.md`、`server/docs/ai/adr/`。

## 易混命令

| 命令 | 实际 |
|------|------|
| `pnpm -F @proj-airi/api-server dev` | **云端资源 API** |
| `pnpm -F @proj-airi/auth-server dev` | **云端 Auth / OIDC** |
| `pnpm -F @proj-airi/server …` | **无效**（旧单体已拆） |
| `pnpm dev:server` | **Channel** `server-runtime`（本机 Hub） |
| `pnpm dev:server-auth` | 认证 **SPA** `apps/ui-server-auth`（不是 Auth 进程本身） |

## 鉴权配套 UI

| 项 | 事实 |
|----|------|
| 应用 | `apps/ui-server-auth` |
| 根脚本 | `pnpm dev:server-auth` |
| 职责 | 打 Auth `/api/auth/*` 的登录 SPA；**不是**主 Stage 舞台 |

## 无云也能做的事

本地 / BYO Provider、本地会话 IDB、舞台渲染、桌宠内嵌 Channel、MCP。

缺云会缺：官方 Provider、账号、Flux / Capacitor、Chat 云同步 `/ws/chat`、托管 LLM/TTS 网关。
