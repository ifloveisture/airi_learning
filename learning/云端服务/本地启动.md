# 本地启动

> 包：`@proj-airi/server` · 路径：`apps/server`

## 定位

本地起云端 API（账号、同步、计费、OpenAI 兼容网关）。**不是**本机 Channel Hub（`pnpm dev:server` / `server-runtime`）。

## 前置条件

缺任一项，进程会在 `parseEnv` 处失败（或稍后连不上库）。

| # | 条件 | 说明 |
|---|------|------|
| 1 | `apps/server/.env.local` 存在 | `dev` 脚本经 `dotenvx -f .env.local` 加载；**只认这个文件**。有 `.env` 不够，需复制：`Copy-Item apps/server/.env apps/server/.env.local` |
| 2 | 可连通的 Postgres | `DATABASE_URL` |
| 3 | 可连通的 Redis | `REDIS_URL` |
| 4 | Better Auth 密钥 | `BETTER_AUTH_SECRET`（会话签名；部署间须稳定） |
| 5 | Google / GitHub OAuth | `AUTH_GOOGLE_CLIENT_ID` · `AUTH_GOOGLE_CLIENT_SECRET` · `AUTH_GITHUB_CLIENT_ID` · `AUTH_GITHUB_CLIENT_SECRET`（四项均必填，缺一不起服） |
| 6 | LLM 路由主密钥 | `LLM_ROUTER_MASTER_KEY`：base64，解码后**正好 32 字节** |

真源：`apps/server/src/libs/env.ts`（Valibot schema）。

### 可选（不起服也可缺）

| 变量 / 能力 | 说明 |
|-------------|------|
| Stripe | `STRIPE_SECRET_KEY` · `STRIPE_WEBHOOK_SECRET` |
| Resend | `RESEND_API_KEY` 等；未配时邮件流到发送才报错 |
| OTel / Langfuse | `OTEL_EXPORTER_OTLP_ENDPOINT` 与/或 Langfuse Key；未配时日志会写 `OpenTelemetry disabled`，**不是启动失败** |

## 命令

| 目的 | 命令 |
|------|------|
| 开发 API | `pnpm -F @proj-airi/server dev`（`dotenvx` + `.env.local`，`tsx watch` 跑 `src/bin/run.ts api`） |
| DB | `db:generate` / `db:push`（以包 scripts 为准） |
| Auth schema | `auth:generate`（Better Auth） |
| 可选 OTel | `docker compose -f apps/server/docker-compose.otel.yml up -d` |

密钥勿提交。细则见 `apps/server/CLAUDE.md`、`docs/ai-context/`。

## 易混命令

| 命令 | 实际 |
|------|------|
| `pnpm -F @proj-airi/server dev` | **云端** `apps/server` |
| `pnpm dev:server` | **Channel** `server-runtime`（本机 Hub） |

## 常见失败

| 现象 | 原因 |
|------|------|
| `Expected "DATABASE_URL" but received undefined` | 无 `.env.local`，或文件里未填；脚本对缺失文件是 `--ignore=MISSING_ENV_FILE`，会静默空跑再校验失败 |
| 仅见 `[otel-preload] OpenTelemetry disabled` | 正常提示，不是起服失败；继续往下看是否有 `Invalid environment variables` |
| OAuth / `LLM_ROUTER_MASTER_KEY` 校验失败 | 四项 OAuth 或 32 字节主密钥未按 schema 填 |

## 鉴权配套 UI

| 项 | 事实 |
|----|------|
| 应用 | `apps/ui-server-auth` |
| 根脚本 | `pnpm dev:server-auth`（若有） |
| 职责 | 打 `/api/auth/*` 的登录 SPA；**不是**主 Stage 舞台 |

## 无云也能做的事

本地 / BYO Provider、本地会话 IDB、舞台渲染、桌宠内嵌 Channel、MCP。

缺云会缺：官方 Provider、账号、Flux、Chat 云同步 `/ws/chat`、托管 LLM/TTS 网关。

## 现状

| 状态 | 说明 |
|------|------|
| 可启用 | 满足前置条件后本地 `dev`；依赖外部 Postgres / Redis / OAuth 应用 |

## 边界

- 云端 API ≠ 本机 Channel Hub。
- Stage 本地聊天可不启本服务；启用后才有账号、Flux、云同步与托管网关。
