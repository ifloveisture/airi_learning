## 命令 / env（摘）

```bash
docker compose -f apps/server/docker-compose.otel.yml up -d
# 前端：VITE_ENABLE_POSTHOG 等（见 posthog 配置）
```

## 现状

OTel/Grafana、Langfuse（chat+TTS 阶段）、PostHog 多 surface 已接线。

## 边界

- **Grafana**：聚合与告警，不存完整 prompt 正文。
- **Langfuse**：不替代 `flux_transaction` 账本。
- **PostHog**：不管 per-request LLM 扣费明细。
