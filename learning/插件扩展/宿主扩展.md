# 宿主扩展

## ExtensionHost 启动

```text
main/index.ts
  → setupExtensionHost
  → apps/stage-tamagotchi/src/main/services/airi/plugins/
  → host（ExtensionHost from @proj-airi/plugin-sdk/plugin-host）
```

| 项 | 事实 |
|----|------|
| 清单目录 | `extensions/v1`（userData 下） |
| 状态文件 | `extensions-v1.json` |
| IPC | `shared/eventa/plugin/host.ts`（list / load / unload / setEnabled…） |
| 能力契约 | `shared/eventa/plugin/{capabilities,tools,assets}.ts` |

## Kit 概念（plugin-sdk）

作者把 kit 当普通 API，不关心传输：

| 名 | 含义 |
|----|------|
| `*KitApis` | Eventa invoke 契约 |
| `*KitService` | Host 侧真实现（副作用） |
| `*Kit` / `create*Kit` | `ctx.kits.use(...)` |
| 客户端实例 | 如 `gamelets.mount(...)` |

跨进程复用同一套 Eventa；本地可直调 service。详见 `packages/plugin-sdk/README.md`。

桌面专用：`packages/plugin-sdk-tamagotchi`（widget / gamelet / tools…）；实现挂在 `main/services/airi/plugins/kits/`。

## Host 型样例

| 例子 | 路径 |
|------|------|
| 象棋 gamelet | `plugins/airi-plugin-game-chess` |
| 内置样例 | `…/plugins/examples/devtools-sample-plugin/` |
| gamelet kit | `plugin-sdk-tamagotchi/src/kits/gamelet/` |

特征：依赖 `plugin-sdk`（+ tamagotchi kits），由 **ExtensionHost 加载**，不是 `server-sdk` 连 Channel。

## 两条扩展形态对照

| | Channel 插件 | Host 插件 |
|--|--------------|-----------|
| 连接 | `server-sdk` → Hub | ExtensionHost 加载 |
| 进程 | 常独立 | 宿主进程内扩展 |
| 例子 | web-extension、discord-bot | game-chess |

## 阅读顺序

1. `plugin-sdk/README.md` Kit 命名
2. `services/airi/plugins` 入口 / host
3. `airi-plugin-game-chess` setup
4. Eventa `shared/eventa/plugin/*`
