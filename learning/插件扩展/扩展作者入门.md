# 扩展作者入门

> 写扩展前先分清两条形态。协议细节：[模块通道](./模块通道.md)；Host 基建：[宿主扩展](./宿主扩展.md)。

## 先选形态

| | Channel 插件 | Host 插件 |
|--|--------------|-----------|
| 连接 | `server-sdk` `Client` → Hub WS | ExtensionHost 读 `extension.airi.json` |
| 进程 | 常独立进程 | 桌宠主进程内 |
| 清单 | 无（announce 自报模块） | `extensions/v1` + `extensions-v1.json` |
| 例子 | Discord bot · `vscode-airi` · web-extension | gamelet（象棋样例）· `devtools-sample-plugin` |
| SDK 稳定度 | Channel 主路径较稳 | `plugin-sdk` 标注 APIs **WIP** / Active design |

```text
只要「推上下文 / 收发模块事件」→ Channel
要「嵌进桌宠 UI / gamelet / widget」→ Host
```

## Channel 作者最短链

1. [模块通道](./模块通道.md)：`plugin-protocol` 事件名
2. `packages/server-sdk`：`Client.connect` + announce
3. 样板：`integrations/vscode/vscode-airi`（推 `context:update`）或 [Discord竖切](../通道机器人/Discord竖切.md)
4. 本地 Hub：`pnpm dev:server` 或桌宠内嵌 channel-server（默认 **6121**）

## Host 作者最短链

1. `packages/plugin-sdk/README.md`（Kit 命名：`*KitApis` / `*KitService` / `create*Kit`）
2. Manifest：`ExtensionManifestV1`（`packages/plugin-sdk/.../plugin-host/shared/types.ts`）
   - kind：`manifest.extension.airi.moeru.ai` · `apiVersion: "v1"`
3. 样例清单：`apps/stage-tamagotchi/.../plugins/examples/devtools-sample-plugin/extension.airi.json`
4. 安装位置：`<userData>/extensions/v1`；状态：`extensions-v1.json`
5. 桌宠 kits：`packages/plugin-sdk-tamagotchi`（gamelet / widget / tools）
6. 装配：`main/services/airi/plugins` · `kits/` · Eventa `shared/eventa/plugin/*`
7. 行为形状（象棋）：看 `plugins/index.test.ts` 里 `defineExtension` → `modules.register` → `kits.use(gameletKit)` → `gamelets.mount`
   （仓库里 `airi-plugin-game-chess` 可能仅剩 package 壳，以测试与 design doc 为准）
