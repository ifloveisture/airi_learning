# 模块通道

## 包关系

```text
plugin-protocol     事件名与 payload（Eventa）
        ↓
server-shared       Channel WS 类型、错误等（再导出 protocol）
        ↓
server-runtime      Hub：路由、鉴权、announce、投递
        ↕ WebSocket
server-sdk          Client / ExtensionPeer
```

与云端 `apps/server` **正交**。桌宠默认把 Hub 嵌在 `main/services/airi/channel-server`（端口常 `SERVER_CHANNEL_PORT` 或 **6121**）。

## 关键事件名

真源：`packages/plugin-protocol/src/types/events.ts`（名称以源码为准）。

| 类别 | 示例 |
|------|------|
| 输入 | `input:text` · `input:text:voice` · `input:voice` |
| 输出 | `output:text` |
| 模块 / 扩展生命周期 | `module:*` · `extension:*` · `peer:*` |
| 游戏等 | `spark:command` |
| 上下文 | 如 `context:update`（Vision / 外部模块常用） |

Discord 竖切如何把 IM 映到 `input:text` → [通道机器人](../通道机器人/)。

## Client 用法（要点）

路径：`packages/server-sdk`

1. `new Client({ name, token?, autoConnect?, … })`
2. `await client.connect()` — socket +（可选）认证 + **announce 成功**
3. 握手：`module:authenticate`（有 token）→ `extension:module:announce`（name / identity / possibleEvents / configSchema / dependencies）
4. `onEvent` / `send` / `sendOrThrow`；`connectionStatus` · `isReady`
5. 扩展级：`ExtensionPeer` 的 `announceExtension` / `announceModule`

## Stage 侧

UI 经 channel 相关 store（mods API）用 `server-sdk` 连本机 Hub，收外部事件、推上下文。
