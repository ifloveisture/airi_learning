# 口型驱动

> 串：TTS / 播放音量 → Live2D（及他端）嘴型。
> 挂点见 [语音合成](../语音交互/语音合成.md) · [Live2D与VRM](../舞台呈现/Live2D与VRM.md) · [视觉动捕](../舞台呈现/视觉动捕.md)。

## Live2D 主公式

源码：`packages/model-driver-lipsync/src/live2d/index.ts`（`createLive2DLipSync`）
前端分析：wLipSync AudioWorklet → AEIOUS 元音权重，再映射到 AEIOU。

对每个元音：

```text
amp = min(volume * volumeScale, 1) ^ volumeExponent
weight = min(cap, rawVowelWeight * amp)
```

嘴张合标量：

```text
mouthOpen = max(各元音 weight)   # 再经平滑
```

| 参数 | 默认 | 含义 |
|------|------|------|
| `volumeScale` | `0.9` | 音量放大后再截到 1 |
| `volumeExponent` | `0.7` | 压高峰，嘴张合更自然 |
| `cap` | `0.7` | 单元音权重上限 |
| `mouthUpdateIntervalMs` | `40` | ≈25fps 更新，减抖 |
| `mouthLerpWindowMs` | `120` | 嘴张合 lerp 窗；`0` 关平滑 |

平滑（窗口 &gt; 0 时）：

```text
alpha ≈ Δt / mouthLerpWindowMs
smoothed += (raw - smoothed) * alpha
```

## 在闭环中的位置

```text
[切段与播控] SpeechPipeline 播放
  → 音频节点 volume / wLipSync
  → 本篇 morph
  → Live2DScene / 其他渲染绑定
```

口型**不**参与聊天决策；它是表达层最后一跳。Vision / MediaPipe 动捕是另一条输入（看屏/看人），不要和 lipsync 混成同一算法——见 [视觉动捕](../舞台呈现/视觉动捕.md)。
