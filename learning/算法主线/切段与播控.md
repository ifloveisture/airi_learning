# 切段与播控

> 串：麦 → STT → 进聊天；以及 LLM 流式文本 → TTS → 播放。
> 产品路径见 [听力转写](../语音交互/听力转写.md) · [语音合成](../语音交互/语音合成.md) · [音频管线](../语音交互/音频管线.md)。

## 1. VAD：何时算「说完一句」

源码：`packages/stage-ui/src/workers/vad/vad.ts`（Silero ONNX）

| 常数 | 默认 | 含义 |
|------|------|------|
| `speechThreshold` | `0.3` | 概率高于此 → 开始（或维持）说话 |
| `exitThreshold` | `0.1` | **已在录**时，概率 ≥ 此仍算说话（迟滞，防抖） |
| `minSilenceDurationMs` | `400` | 连续静音够长 → 句末 |
| `minSpeechDurationMs` | `250` | 短于此时长的段丢弃 |
| `speechPadMs` | `80` | 句首前垫样，少吞字头 |

判定要点：

```text
speechProb > 0.3
  OR (正在录音 AND speechProb >= 0.1)
→ 视为说话

录音中静音累计 ≥ 400ms
  AND 已录时长 ≥ 250ms
→ 交出一段去 STT
```

改阈值会直接影响「空转写」与「句被截断」。桌宠/首页 VAD 路径见 [聊天与语音路径](../多端应用/网页端/聊天与语音路径.md)。

## 2. TranscriptBuffer：碎片如何合成一句

源码：`packages/pipelines-audio/src/transcript-buffer.ts`
产品例：桌宠 `apps/stage-tamagotchi/.../pages/index.vue` 使用 `flushDelayMs: 1200`。

| 规则 | 默认 / 产品值 | 作用 |
|------|---------------|------|
| 延迟 flush | 桌宠 **1200ms**（选项必填，无全局默认） | 停顿仍并进同一轮 |
| 立即 flush | 缓冲文本 ≥ **80** 字符 | 长句不等待 delay |
| 拼接 | CJK 邻接无空格；拉丁补空格 | 可读性 |

Flush 后回调通常进 `ingest`（或桌宠 `requestIngest`）。
**VAD 切段**与 **Buffer 合并**是两层：VAD 决定「录哪段」，Buffer 决定「多段 STT 是否并成一次发送」。

## 3. TTS chunker：流式文本何时开说

源码：`packages/pipelines-audio/src/processors/tts-chunker.ts`

| 常数 | 默认 | 含义 |
|------|------|------|
| `minimumWords` | `4` | 软门槛：通常攒够再吐 |
| `maximumWords` | `12` | 硬上限：超词数强制切 |
| `boost` | `2` | 前 **2** 段可低于 `minimumWords` 就吐（降首包延迟） |

触发 `reason`：

| reason | 条件 |
|--------|------|
| `hard` | 硬标点（句号等） |
| `limit` | 词数 > `maximumWords` |
| `boost` | 前几段抢首包 |
| `flush` / `special` | 显式 flush 指令或特殊 token |

另有 narrative 括号过滤（如 `<laugh>`、`[sigh]`），避免旁白标签进 TTS。

## 4. 播放优先级与并发

源码：`packages/pipelines-audio/src/priority.ts` · `speech-pipeline.ts`

| 级别 | 数值 |
|------|------|
| `critical` | 300 |
| `high` | 200 |
| `normal` | 100（缺省） |
| `low` | 0 |

- 待发 TTS 按 **优先级降序**，同级按 **创建时间升序**
- `ttsMaxConcurrent` 默认 **4**
- PlaybackManager 可配置溢出策略（如 `steal-lowest-priority`）

## 和上下游怎么接

```text
VAD 句末 → STT → TranscriptBuffer.flush
  → [编排与上下文] ingest
  → LLM token 钩子（Stage.vue）
  → SpeechPipeline + chunker
  → 播放 → [口型驱动]
```
