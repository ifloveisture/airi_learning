# 学习路径 · 算法主线

本域写**判定规则与常数**，不替代功能域跟包。先建立主轴印象，再按问题下钻。

## 目标

- 能复述「说完 → 想完 → 说回去」的决策顺序
- 知道切段 / 队列 / 调度 / 回忆 / 口型各看哪篇
- 改阈值或排「为什么没进聊天」时先回本域表，再开源码

## 步骤

| # | 读什么 | 文档 |
|---|--------|------|
| 1 | 总图 + 主成功路径 + 常见中断 | [端到端闭环](./端到端闭环.md) |
| 2 | VAD · 句末 · TTS chunk · 播放优先级 | [切段与播控](./切段与播控.md) |
| 3 | FIFO · generation 作废 · 上下文 400 | [编排与上下文](./编排与上下文.md) |

## 按问题跳读

| 问题 | 先看 |
|------|------|
| 话说完很久才进输入 / 聊天 | 闭环中断表 → 切段与播控 |
| 连发乱序或旧回复冒出 | 编排与上下文 |
| Bot 不回或太慢 | Agent调度 |
| 回忆不对题 | 记忆检索 |
| 嘴张合怪 | 口型驱动 |
