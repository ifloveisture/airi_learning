# 技术栈备忘

> 对照仓库：`v0.11.3` · `pnpm-workspace.yaml` catalog · `AGENTS.md`
> 版本会变，以 catalog 为准；本页只记**主要技术与用途**。

## 一句话

**Vue 3 + TypeScript + Vite** 的多端舞台；桌面 **Electron**；移动 **Capacitor**；云端 **Hono**；包管理 **pnpm catalog + Turbo**；跨进程用 **Eventa**，装配用 **injeca**。

## 工程与语言

| 技术 | 版本（约） | 用途 |
|------|------------|------|
| TypeScript | ^5.9 | 全仓主语言 |
| pnpm | 10.33.0 | workspaces + **catalog** 统一依赖 |
| Turbo | ^2.9 | `build` 等任务编排与缓存 |
| tsdown | ^0.21 | 多数 packages 打 ESM / d.ts |
| Vite | ^8 | Web / 包开发构建 |
| Node | 以官方文档 / CI 为准 | 工具链与部分 services |

## 前端核心（Stage 三端共用）

| 技术 | 版本（约） | 用途 |
|------|------------|------|
| Vue | ^3.5 | UI 框架（Composition API + `<script setup>`） |
| Vue Router | ^5 | 路由；配合 **unplugin-vue-router** 文件系统路由 |

## 多端运行时

| 面 | 技术 | 用途 |
|----|------|------|
| Web | Vite + PWA 相关插件 | `apps/stage-web` |
| 桌面 | **Electron ^41** · electron-vite ^5 · electron-builder ^26 | `apps/stage-tamagotchi`（现行桌面，**非 Tauri**） |
| 桌面 IPC | **@moeru/eventa** | 类型安全 IPC / RPC（契约在 `src/shared`） |
| 桌面 DI | **injeca** | 主进程服务装配（拼写不是 injecta） |
| 移动 | **Capacitor 8**（iOS / Android） | `apps/stage-pocket`（实验） |
| 渲染 sidecar | Godot（C# 工程在 `engines/`） | 可选 3D 舞台，非主 Agent |
