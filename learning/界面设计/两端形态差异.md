# 两端形态差异

> **同语汇、异形态**：配色、字体、磨砂控件、`WidgetStage` 共享；差在窗口与交互壳。
> 端侧专题：[网页端](../多端应用/网页端/) · [桌宠端](../多端应用/桌宠端/)。

## 对照总表

| 维度 | 网页端 `stage-web` | 桌宠端 `stage-tamagotchi` |
|------|--------------------|---------------------------|
| 画布 | 浏览器整页 | 无边框透明置顶 `BrowserWindow` |
| 背景 | `BackgroundProvider`（波浪/图/透明） | 窗透明，见桌面墙纸；无 Provider |
| 顶栏 | Header / MobileHeader | 无；功能进 Controls Island / 托盘 |
| 聊天 | 首页内嵌 InteractiveArea | 独立 Chat 窗口（可 chat-sync） |
| 舞台控件 | ViewControlSlider 等 | ControlsIsland · StatusIsland · ResourceStatusIsland |
| 路由转场 | `StageTransitionGroup`（ui-transitions） | 主路径未挂 |
| 主题色采样 | `useBackgroundThemeColor` | 无背景采样；Hue 设置仍共享 |
| 指针 | 普通 DOM | 透明像素穿透 + `setIgnoreMouseEvents` |
| 关舞台 | 关标签 | 通常 hide 到托盘 |

## 桌宠专有视觉行为

### 透明窗

`apps/stage-tamagotchi/src/main/windows/shared/window.ts` → `transparentWindowConfig()`：`frame: false`、`transparent: true`、`hasShadow: false`。主窗、caption、widgets、overlay 等复用。

### 点击穿透

逻辑在 `renderer/pages/index.vue`：

- Live2D：画布 alpha 采样（`stage-ui` canvas-alpha）
- VRM：Three 命中透明（`stage-ui-three`）
- 控件岛 / 状态岛 / 边框 resize / 听力对话框内 **不穿透**
- 开穿透时：`setIgnoreMouseEvents(true, { forward: true })`；可配合模型淡出（fade-on-hover）

IPC：`main/services/electron/window.ts`。说明窗：`#/notice/fade-on-hover`。

### Controls Island

`renderer/components/stage-islands/controls-island/`：

- 浮动磨砂控制条：主题、麦克风、设置、聊天、置顶、fade-on-hover、profile…
- 悬停检测；约 1.5s 无操作收起
- 图标尺寸：`settings.controlsIslandIconSize`（general 设置，仅 Electron）

这是桌宠把「Web 顶栏 + 部分 Chat 动作」收成**桌面悬浮岛**的形态答案，不是另一套配色系统。

## Web 专有视觉层

- 全页背景 + 右侧玻璃聊天柱
- `ui-transitions` 路由舞台动画
- NProgress 条跟 chromatic
- PWA / 移动 Header 与 MobileInteractiveArea

## 改样式时怎么选边

| 需求 | 改哪里 |
|------|--------|
| 两边聊天面板都要更圆 / 更糊 | `stage-layouts` Chat* |
| 只改 Web 首页拼装 | `apps/stage-web/src/pages/index.vue` |
| 只改桌宠岛 / 穿透 | `stage-tamagotchi` renderer islands + `pages/index.vue` |
| 主色 / Dark | 共享 settings + `theme.ts` + 两端 App.vue（已接线则只改 store/UI） |
| 角色渲染 | `stage-ui` / `stage-ui-*`（见 [舞台呈现](../舞台呈现/)） |
