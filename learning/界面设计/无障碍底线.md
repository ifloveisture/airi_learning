# 无障碍底线

## 定位

AIRI 尚无完整 a11y 专章；本页是**出稿与改 UI 时的底线**，基于 reka-ui 原语与现有焦点环实践。

## 真源习惯

| 项 | 说明 |
|----|------|
| 原语 | `packages/ui` 多包一层 reka-ui（焦点、键盘行为优于自造 div） |
| 焦点 | Button 等常见 `focus:ring-2` |
| 禁用 | `disabled` + `opacity-50`，保留外形 |

## 检查清单

- [ ] 图标按钮有 `title` / aria 或可见文字，不靠「猜图标」
- [ ] Light/Dark 下正文对面板对比度可读（磨砂底上测字色）
- [ ] 不把**唯一**关键操作做成无法聚焦的纯 hover（桌宠 Controls Island 需有托盘/设置等等效入口意识）
- [ ] 动效过强时设置里可关过渡（勿强制癫痫式闪烁）
- [ ] 表单错误不要只靠颜色，需文案

## 跟读

1. Histoire 里 Tab/走查 Button、Field 键盘行为
2. 改自定义控件时优先包 reka 原语
3. 半透明壳上用实色字（见同域视觉规范）

## 现状

底线级；无障碍审计未成门禁。

## 边界

- 不替代法律合规 a11y 审计。
- 桌宠穿透模式本身会牺牲部分「屏幕阅读器语义」，产品取舍需显式知晓。
