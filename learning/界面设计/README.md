# 界面设计

> **管什么**：Web / 桌宠（及共享包）的视觉气质、体验原则、视觉规范、关键画面、色板主题、字体动效、组件分层
> **不管什么**：业务编排（回 [角色对话](../角色对话/)）、模型渲染算法（回 [舞台呈现](../舞台呈现/)）、端壳启动细节（回 [多端应用](../多端应用/)）

## 一句话

**同一套 Stage UI 语汇**（圆角、半透明 blur、可调色相、圆体字、角色居中），两端差在**壳**：Web 是浏览器整页 + 背景；桌宠是透明置顶窗 + 点击穿透 + Controls Island。
