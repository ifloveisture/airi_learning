## 产品气质（一句话）

**ACG / 数字伴侣舞台**：角色（Live2D / VRM）是视觉中心；UI 是围着角色的轻量、半透明、可换色「控件层」，不是企业后台仪表盘。

对照产品意象：Neuro-sama 一类「直播虚拟角色容器」（见根 `README.md`、`apps/stage-web/README.md`）。

## 落地后长什么样（代码侧特征）

这些不是「设计系统白皮书条款」，而是仓库里反复出现的视觉词汇：

| 特征 | 代码侧表现 |
|------|------------|
| 角色居中 | 首页挂 `WidgetStage`（`stage-ui` scenes） |
| 磨砂控件 | `backdrop-blur-md` + 半透明 `primary-*` / `neutral-*` 底 |
| 圆角岛 | `rounded-xl`、聊天容器 4px 淡色描边 |
| 可调主色 | `--chromatic-hue` + Uno `primary-*`（见 [色板与主题](./色板与主题.md)） |
| 圆体字 | 舞台 layout 用 `font-cute`（Nunito / ChillRoundM / Kiwi Maru…） |
| 活泼图标 | 设置入口偏好 Solar **bold-duotone** |
| 舞台转场 | Web 用 `@proj-airi/ui-transitions`（如 `bubble-wave-out`） |

## 官方工具章摘要

`design-guidelines/tools.md`：

- 样式引擎：**UnoCSS**（用法对齐 Tailwind 语汇）
- 基础色建议：`neutral`、`pink`、`violet`、`cyan`
- 改色度时优先挑**实色**（Refactoring UI），少用透明度硬凑对比度；半透明用于「叠在角色上的壳」是排版意图时除外
- 交互色可参考 **Radix Colors**
- 背景图案可参考 SVG Backgrounds、Finisher header 等外链

与代码的关系：运行时主色已由 **Chromatic 色相系统**接管（不是写死某一档 pink），但 `neutral` + 粉紫青氛围仍是默认观感。
