# 色板与主题

> 真源：根 `uno.config.ts` · `packages/ui/src/fallback.css` · `packages/stage-ui/src/stores/settings/theme.ts` · 两端 `App.vue`

## 默认观感

官方工具章建议基础色：`neutral` / `pink` / `violet` / `cyan`。

运行时真正驱动「品牌主色」的是 **Chromatic**：

| 项 | 值 / 位置 |
|----|-----------|
| 默认色相 | `220.44`（偏蓝紫） |
| Uno 预设 | `presetChromatic({ baseHue: 220.44, colors: { primary: 0, complementary: 180 } })` |
| CSS fallback | `--chromatic-hue` 与各级 `--chromatic-chroma-*`（`packages/ui/src/fallback.css`） |
| 工具类 | `bg-primary-*`、`text-primary-*`、`border-primary-*` 等（由 preset 生成） |

chroma 用 hue 的余弦微调，使不同色相饱和度更稳（见 `fallback.css`）。

## 生效链路

```text
设置页 color-scheme
  → Pinia useSettingsTheme（localStorage: settings/theme/colors/hue）
  → App.vue watch → documentElement.style --chromatic-hue
  → Uno primary-* / 组件内 oklch(... var(--chromatic-hue))
```

| 步骤 | 路径 |
|------|------|
| 状态 | `packages/stage-ui/src/stores/settings/theme.ts`（`DEFAULT_THEME_COLORS_HUE = 220.44`） |
| 写入 DOM | `apps/stage-web/src/App.vue`、`apps/stage-tamagotchi/src/renderer/App.vue` |
| 动态色相 | `themeColorsHueDynamic` → class `dynamic-hue`（`@keyframes hue-anim`，约 10s 循环） |
| Dark | `packages/ui/src/composables/use-theme.ts`（`useDark` + localStorage） |

组件也可直接写 OKLCH，例如波浪背景、十字网格、NProgress（Web `apps/stage-web/src/styles/main.css`）。

Logo 等用 `filter: hue-rotate(calc(var(--chromatic-hue) * 1deg))`（如 `HeaderLink.vue` / `MobileHeaderLink.vue`）。

## 背景与 theme-color

| 机制 | 路径 | 作用 |
|------|------|------|
| Background store | `packages/stage-layouts/src/stores/background.ts` | Wave / Image / Transparent；用户图进 IndexedDB；`sampledColor` |
| `useThemeColor` | `packages/stage-layouts/src/composables/theme-color.ts` | 更新 `<meta name="theme-color">` |
| `useBackgroundThemeColor` | 同上 | 按背景采样同步（**Web 首页**用；桌宠主舞台无 BackgroundProvider） |

预设示例：`colorful-wave`、`transparent`。Image 可开 blur（`BackgroundProvider`）。

**注意**：`SakuraPetal.vue` / `Line1.vue` / `TicTacToe.vue` 仍在 `Backgrounds/` 目录，但当前 **未接入 Provider**（无 import）；别当成产品主路径。

## 设计注意（资料 + 实践）

1. **对比度**：工具章劝少用 alpha 硬凑色度；磨砂壳（`primary-50/50` + blur）是「叠角色」意图，正文/标签仍尽量用实色。
2. **Dark**：`dark:` 变体与 `html.dark` 背景在 `apps/stage-web/src/styles/main.css`；设置 layout 会固定 meta theme-color 为浅/深灰。
3. **从背景取色**：`applyPrimaryColorFrom` / `isColorSelectedForPrimary` 用 culori 转 OKLCH 比 hue（`theme.ts`）。
