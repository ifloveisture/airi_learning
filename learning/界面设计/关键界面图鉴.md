## 1. Web 舞台首页

**路由**：`/` · layout `stage`
**文件**：`apps/stage-web/src/pages/index.vue`

```text
┌──────────────────────────────────────────────────┐
│ [Logo]                              [About][Avatar] │  ← Header（轻）
│ ┌────────────────────────────────────────────────┐ │
│ │                                                │ │
│ │              Live2D / VRM 舞台                  │ │  ← 视觉重心
│ │              （可全bleed 感）                    │ │
│ │                              ┌───────────────┐ │ │
│ │                              │ ░░ 聊天历史 ░░ │ │ │  ← ChatContainer
│ │                              │ ░░ 输入 / 麦 ░░ │ │ │     rounded-xl
│ │                              │ [背景][…]     │ │ │     blur + primary 淡底
│ │                              └───────────────┘ │ │
│ └────────────────────────────────────────────────┘ │
│          ↑ BackgroundProvider（波浪 / 图 / 透明）   │
└──────────────────────────────────────────────────┘
```

**标注要点**

| 元素 | 设计注意 |
|------|----------|
| 背景 | 可换；与主题色可联动采样 |
| 角色 | 最大；UI 不得压成「小窗预览」 |
| 聊天柱 | 玻璃；描边淡 primary；勿实心白卡 |
| 移动 | 无右侧柱时 → 底输入 + 浮动磨砂方钮 |

对照：[舞台壳与布局](./舞台壳与布局.md) · [网页端/首页与舞台](../多端应用/网页端/首页与舞台.md)

## 2. 设置总览

**路由**：`/settings`
**文件**：`packages/stage-pages/src/pages/settings/index.vue`

```text
┌─────────────────────────────┐
│  ← 返回 / 标题（settings 壳） │
│                             │
│  ┌───────────────────────┐  │
│  │ ◎ 标题                 │  │  ← IconItem 行
│  │   短描述…              │  │     Solar duotone
│  └───────────────────────┘  │
│  ┌───────────────────────┐  │
│  │ ◎ …                   │  │
│  └───────────────────────┘  │
│                             │
│              ⚙（巨大水印）   │  ← 装饰，不抢点
└─────────────────────────────┘
```

**体验**：点击可带 Ripple 再进入；列表纵向、低栏数。不要改成密集瓷砖仪表盘。

## 3. 配色页

**路由**：`/settings/system/color-scheme`
**文件**：`packages/stage-pages/src/pages/settings/system/color-scheme.vue`

```text
┌─────────────────────────────────┐
│ 自定义颜色                        │
│ 主色          [动态 RGB 开关]     │
│ ═════○══════ ColorHueRange ═══  │
│                                 │
│ 主题预设                         │
│ [default] [morandi] [monet] …   │
│  色板圆点 / 色卡                  │
└─────────────────────────────────┘
```

**标注要点**

- 预设：morandi / monet / japanese / nordic / chinese 等（见 `color-presets.json`）
- 动态开时：色相轮转，预设「选中」应弱化
- 出稿展示 **滑条 + 预设色点**，不要只给一个死 hex

## 4. 设置 · 常规（含 Dark）

**路由**：`/settings/system/general`
字段在 `settings-general-fields.vue`：Dark、过渡开关、桌宠岛图标尺寸等。

设计含义：**主题与动效偏好集中在系统**，不要散落在每个业务页各做一套 Dark 开关。

## 5. 桌宠主舞台 + Controls Island

**文件**：`apps/stage-tamagotchi/src/renderer/pages/index.vue`
**岛**：`renderer/components/stage-islands/controls-island/`

```text
        （桌面墙纸可见）
┌─────────────────────────────────┐  ← 无边框透明窗
│                                 │
│          角色（可穿透空白）        │
│                                 │
│                    ┌─────┐      │
│                    │ ☀ 🎤 │      │  ← Island：rounded-xl
│                    │ ⚙ 💬 │      │     blur + neutral 壳
│                    └─────┘      │     闲置收起
└─────────────────────────────────┘
```

**必须在稿上标明的交互**

| 状态 | 表现 |
|------|------|
| 指针在透明像素 | 点击落到桌面（穿透） |
| 指针在角色 / 岛 | 可点；穿透关 |
| 岛闲置 | 约 1.5s 后收起 |
| 无内嵌大聊天柱 | 聊天在别窗 |

对照：[两端形态差异](./两端形态差异.md) · [桌宠端/舞台与穿透](../多端应用/桌宠端/舞台与穿透.md)

## 6. 原语（Histoire）

在 `pnpm dev:ui` 中优先看：

| 组件 | 看什么 |
|------|--------|
| Button | primary/secondary/…、sm/md/lg、loading/disabled |
| Field* | 标签 / 说明字阶、gap |
| ColorHueRange | 与配色页一致 |
| Checkbox / Select / Combobox | 圆角 xl/lg、focus 环 |

规范数值汇总：[视觉规范](./视觉规范.md)。

## 7. 画面 ↔ 原则对照

| 画面 | 对应原则 |
|------|----------|
| Web 舞台 | 舞台优先、壳轻核心重 |
| 设置总览 | 插画感入口、非密表 |
| 配色 | 可换色可 Dark |
| 桌宠岛 | 同语汇异形态、穿透可达性 |
