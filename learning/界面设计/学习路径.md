# 学习路径 · 界面设计

## 目标

- 说清 AIRI Stage 的视觉气质与灵感来源
- 掌握体验原则与可复用的视觉尺（圆角 / 字号 / 磨砂等）
- 跟完主题色从设置 → CSS 变量 → Uno `primary-*` 的链路
- 知道改 UI 该动 `ui` / `stage-layouts` / `stage-ui` / 端壳哪一层
- 分清 Web 与桌宠「同语汇、异形态」

> 设计师请优先走 [设计师向路径](./设计师向路径.md)，再按需回到本页工程步骤。

## 最短动手闭环

| 目标 | 怎么做 |
|------|--------|
| 调主色 | `pnpm dev:web` → 设置 → 系统 → 配色；看 `documentElement --chromatic-hue` |
| 看组件变体 | `pnpm dev:ui`（Histoire · `stage-ui`） |
| 改原语 | 动 `packages/ui`，同步 `docs/ai/context/ui-components.md` |
| 改舞台壳（Header/Chat） | 动 `packages/stage-layouts` |
| 看路由转场 | Web 首页 meta `stageTransition` + `ui-transitions` |
| 对照图鉴截图 | 按 [关键界面图鉴](./关键界面图鉴.md) 清单拍 Light/Dark |
