# 组件与样式约定

## 包分层（改 UI 先认层）

```text
apps/stage-web | stage-tamagotchi
  → stage-pages / stage-layouts
    → stage-ui（业务组件 · stores · scenes）
      → stage-ui-live2d / three / …
        → ui · stage-shared · i18n
```

| 包 | 改什么 | 不要塞什么 |
|----|--------|------------|
| `@proj-airi/ui` | Button、Field*、Input、Range、主题 composable | 聊天 / Provider / 角色业务 |
| `@proj-airi/stage-layouts` | Header、InteractiveArea、Chat 壳、Backgrounds、layout 文件 | LLM 编排、模型加载 |
| `@proj-airi/stage-ui` | 场景、设置业务块、Pinia、scenarios | Electron 窗口 / IPC |
| `@proj-airi/stage-pages` | 共享 settings/devtools **页面** | 端专有壳（auth 等可留在 apps） |
| `@proj-airi/ui-transitions` | 路由级舞台转场 | 业务状态 |

硬约束见 [整体架构](../整体架构.md)：`ui` 禁止依赖 `stage-*`；layouts/pages 消费 stage-ui，禁止反向。

改 `packages/ui` 时同步更新 `docs/ai/context/ui-components.md`（AGENTS 约定）。

## 原语模式（`packages/ui`）

- 底座：**reka-ui**（headless）；上层用 Uno 样式封装。
- 目录习惯：`components/form`、`layouts`、`misc`、`animations`。
- 主题：`composables/use-theme.ts`（Dark）。
- 全局 CSS：`packages/ui/src/main.css` → `fallback.css`（chromatic 变量）等。

业务层也可直接用 reka-ui / vaul-vue（如 BackgroundPicker 桌面 Dialog / 移动 Drawer）——仍应保持视觉词汇一致（圆角、blur、primary）。

## Iconify

| 偏好 | 说明 |
|------|------|
| **Solar bold-duotone** | 设置入口 safelist（`uno.config.ts` `safelistSettingsEntryIcons`）；格式 `i-solar:*-bold-duotone` |
| 也常见 | `i-solar:*-outline`、少量 `ph` / `lucide` |
| 自建集合 | `@proj-airi/lobe-icons`、`@proj-airi/iconify-meteocons`（`presetIcons` + `createExternalPackageIconLoader`） |
| 缩放 | `presetIcons({ scale: 1.2 })` |

## Class 写法（AGENTS）

**推荐**（可读性）：

```vue
:class="['px-2 py-1', 'flex items-center', 'bg-white/50 dark:bg-black/50']"
```

**避免**：

- 超长单行 `class="px-2 py-1 flex ..."`
- 新代码 attributify：`px="2" flex="~ items-center"`（layouts 里仍有遗留，触摸时渐进改掉）

样式优先 **UnoCSS**；要标准化的 shortcut/rule 放根 `uno.config.ts`。

## 视觉词汇速记（写新控件时对齐）

| 模式 | 典型类 |
|------|--------|
| 磨砂面板 | `rounded-xl` + `backdrop-blur-md` + 半透明 `bg-primary-*/*` 或 `bg-neutral-*/70` |
| 聊天容器 | 见 `ChatContainer.vue`：`border … primary-200/20` + `bg-primary-50/50 dark:primary-950/70` |
| 移动浮动钮 | `border-2 … neutral-*/60` + `bg-neutral-50/70` + `backdrop-blur-md` |
| 主色悬停 | `hover:bg-primary-100/60` / `dark:hover:bg-primary-900/40` |
