# 舞台壳与布局

> 共享包本身：[共享页面布局](../多端应用/共享页面布局.md)。本文补**视觉与组装**视角。

## 布局名（文件即名）

`packages/stage-layouts/src/layouts/`：

| 布局 | 视觉角色 |
|------|----------|
| `stage` | 舞台页：`<main h-full font-cute>` + `RouterView`（几乎无铬） |
| `default` | 内容页 + 顶栏 `HeaderLink`（桌宠可隐藏） |
| `home` | 无顶栏全高 |
| `settings` | `PageHeader` + 滚动区；设置 chrome |
| `plain` | 仅 `RouterView` |

页面选用：

```yaml
# <route lang="yaml">
meta:
  layout: stage
```

Web / 桌宠首页均为 `layout: stage`。

## 首页块（共享组件）

| 块 | 路径 | 视觉要点 |
|----|------|----------|
| BackgroundProvider | `components/Backgrounds/Provider.vue` | Wave / Image(+blur) / Transparent |
| Header / MobileHeader | `Layouts/Header*.vue` | Logo（hue-rotate）+ About / Avatar |
| InteractiveArea | `Layouts/InteractiveArea.vue` | 右侧聊天柱：Container + History + ChatArea + Actions |
| MobileInteractiveArea | `Layouts/MobileInteractiveArea.vue` | 底部输入 + 浮动磨砂按钮列 |
| ChatContainer | `Widgets/ChatContainer.vue` | 圆角磨砂主面板（见下） |
| ChatArea | `Widgets/ChatArea.vue` | 输入与菜单；下拉也是 blur + rounded-xl |
| WidgetStage | `@proj-airi/stage-ui` scenes | Live2D / VRM / … |

### ChatContainer（代表性磨砂壳）

```vue
<!-- packages/stage-layouts/src/components/Widgets/ChatContainer.vue -->
border="solid 4 primary-200/20 dark:primary-400/20"
rounded-xl
bg="primary-50/50 dark:primary-950/70"
backdrop-blur-md
```

这是「叠在角色旁的玻璃卡片」范式；新面板优先对齐，而不是另起一套实心灰块。

## 背景机制

| Kind | 表现 |
|------|------|
| Wave | `Backgrounds/default`：十字网格 + 动画波浪（oklch + chromatic） |
| Image | `<img>`，可选 `blur-md scale-110`；上叠 `BackgroundGradientOverlay` |
| Transparent | 透明表面 + class `airi-native-transparent-surface`（给原生透明窗/移动） |

Store：`packages/stage-layouts/src/stores/background.ts`。
Picker：`BackgroundDialogPicker` → stage-ui `background-picker-dialog`。

未接线实验件：`SakuraPetal` / `Line1` / `TicTacToe`（目录在、主路径未用）。

## 谁在用这些壳

| 端 | 组装文件 | 背景 | Header | 内嵌 Chat |
|----|----------|------|--------|-----------|
| Web | `apps/stage-web/src/pages/index.vue` | ✅ Provider | ✅ | ✅ InteractiveArea |
| 桌宠主舞台 | `apps/stage-tamagotchi/src/renderer/pages/index.vue` | ❌（窗本身透明） | ❌ | ❌（独立 chat 窗 + Controls Island） |

桌宠仍复用 `WidgetStage` 与大量 stage-ui；**壳的差异**见 [两端形态差异](./两端形态差异.md)。

## 设置页视觉

- 路由页多在 `stage-pages`；layout `settings`。
- 总览常见 RippleGrid 入口（`settings/index.vue`）。
- 配色页用 `ColorHueRange` 等 `ui` 原语，class 数组写法较新。
