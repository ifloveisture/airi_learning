# 视觉规范

> 从现有实现反推的**工作用尺**，不是独立 Figma Token 文件。
> 真源：`packages/ui`（尤其 `button.vue`）、`packages/stage-layouts`（Chat / 移动控件）、根 `uno.config.ts`。

数字按 Tailwind/Uno 默认间距：`1 = 4px`（`p-2` = 8px）。

## 1. 圆角

| 档位 | 类名 | 用在哪 |
|------|------|--------|
| 控件 / 按钮 | `rounded-lg`（8px） | `Button` 默认外形；多数表单控件 |
| 面板 / 岛 | `rounded-xl`（12px） | `ChatContainer`、移动浮动钮、桌宠 `ControlButton`、Combobox 面板 |
| 胶囊 | `rounded-full` + pill 内边距 | `Button` `shape="pill"`（**默认 shape**）；开关轨 |
| 小块 | `rounded-md` | SelectTab 等紧凑段 |

**出稿**：浮在舞台上的「卡片/岛」→ xl；岛内按钮 → lg 或 pill。

## 2. 间距与密度

| 场景 | 常用 | 说明 |
|------|------|------|
| 按钮内图标与文字 | `gap-2`（8px） | `Button` 内 row |
| 表单 Field 标签区与控件 | `gap-4`（16px） | `Field*` 纵向 |
| 标签与说明 | 标题 `text-sm font-medium`；说明 `text-xs` + `neutral-500` | 说明更淡、更小 |
| 设置总览列表 | 列 `gap-4`；底留白 `pb-12` | 给大水印图标留呼吸 |
| 紧凑工具条 | `p-2` / `gap-2` | 移动浮动钮、桌宠岛按钮 |
| 上传大热区 | `p-6`、`min-h-[120px]` | `InputFileCard` |

设置页整体偏 **中等密度**：分区 Section + 字段，不是电子表格。

## 3. 字号与字体

| 角色 | 类名 | 字体气质 |
|------|------|----------|
| 舞台 UI | 随组件；壳层 `font-cute` | Nunito / 圆体 / 中文圆体栈 |
| 设置正文 | 常 `font-normal`；分区标题可 `text-lg` | 比舞台略「书生」、仍友好 |
| 按钮 sm / md / lg | `text-xs` / `text-sm` / `text-base` | 见下表 |
| 字段说明 | `text-xs text-neutral-500` | Dark：`neutral-400` |
| Logo 字 | 如 `font-quicksand` | Header |

| Button size | pill 内边距 | 字号 |
|-------------|-------------|------|
| sm | `px-3 py-1.5` | `text-xs` |
| md（默认） | `px-4 py-2` | `text-sm` |
| lg | `px-6 py-3` | `text-base` |

square 形状用对称 `p-2`/`p-3`/`p-4`。图标槽常见 `h-4 w-4`。

## 4. 模糊与阴影

| 手段 | 类名 | 用途 |
|------|------|------|
| 标准磨砂 | `backdrop-blur-md` | Button、ChatContainer、移动钮、桌宠岛 |
| 轻磨砂 | `backdrop-blur-sm` | 部分 SelectTab 表面 |
| 描边代阴影 | `border-2` + 低透明 primary/neutral | 玻璃边，少用重 `shadow-xl` |
| 轻阴影 | `shadow-sm`；偶发深色大阴影 | Combobox / 抬起层 |

**气质**：靠 **blur + 透明底 + 细边**，不是 Material 厚阴影卡片。

## 5. 颜色用法（设计表述）

| Token 概念 | 实现 | 设计怎么用 |
|------------|------|------------|
| 主色阶 | `primary-50` … `primary-950`（随 `--chromatic-hue`） | 强调、链接感、聊天壳淡底 |
| 中性 | `neutral-*` | 文字、次要按钮、边框 |
| 危险 / 注意 | `red-*` / `amber-*` | danger / caution 按钮 |
| 壳底示例 | `bg-primary-50/50` + `dark:bg-primary-950/70` | Chat 大面板 |
| 岛底示例 | `bg-neutral-50/80` + `dark:bg-neutral-800/70` | 桌宠 ControlButton |

主题预设名（配色页，供 Moodboard）：**default / morandi / monet / japanese / nordic / chinese**（hex 在 `color-presets.json`）。默认运行色相约 **220°**（蓝紫）。

详细链路 → [色板与主题](./色板与主题.md)。

## 6. 按钮变体与交互态

`packages/ui` `Button`：

| variant | 观感 |
|---------|------|
| `primary` | 主色半透明底 + 细主色边 |
| `secondary` | 中性磨砂 |
| `secondary-muted` | 更淡，靠 hover 显形 |
| `danger` / `caution` | 红 / 琥珀语义 |
| `ghost` / `pure` | 文字或无底 |

态（primary 示例逻辑，其他类似）：

| 态 | 行为 |
|----|------|
| default | 较低透明底 |
| hover | 透明度略升 |
| active | 再升 |
| disabled / loading | 整体 `opacity-50`；loading 换 spinner 图标 |
| focus | `focus:ring-2` |
| 过渡 | `transition-all duration-200 ease-in-out` |

默认 `shape="pill"`，但 class 里仍带 `rounded-lg` 与变体叠加——出稿以 **实机 / Histoire** 为准，新按钮优先复用该组件而非自造。

## 7. 图标

| 项 | 约定 |
|----|------|
| 设置 / 导航主图标 | Solar **bold-duotone**（`i-solar:*-bold-duotone`） |
| 线型补充 | `i-solar:*-outline` 等 |
| 尺寸 | 工具条常见与 `h-4 w-4`；设置水印可极大 |
| 色 | 常跟文字色；Logo 可 `hue-rotate` 跟主题 |

避免同一屏混用 3 套以上图标风格。

## 8. 布局节奏（舞台）

```text
┌─────────────────────────────────────────────┐
│  Header（轻）                    头像/关于   │
│                                             │
│         角色舞台（大）          ┌─────────┐ │
│                                 │ 磨砂聊天 │ │
│                                 │ 圆角 xl  │ │
│                                 └─────────┘ │
└─────────────────────────────────────────────┘
```

移动：底栏输入 + 右侧/侧缘浮动磨砂方钮。
桌宠：无 Header；角色全窗；角上 Controls Island。
