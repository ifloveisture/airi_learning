# 字体与动效

## 字体栈（Uno `theme.fontFamily`）

根 `uno.config.ts`：

| 工具类 | 大致栈 |
|--------|--------|
| `font-sans` | DM Sans |
| `font-sans-rounded` | Comfortaa → DM Sans |
| `font-cute` / `cuteen` / `cutejp` | Nunito → **ChillRoundM** → Kiwi Maru → Comfortaa → DM Sans |
| `font-quanlai` | cjkfonts AllSeto（本地包） |
| `font-xiaolai` | 小赖（本地包） |

舞台 layout（`stage.vue`）默认 `font-cute` —— 这是「圆、软、ACG」气质的主要字体信号。Header Logo 区常见 `font-quicksand`。

### 字体包

| 包 | 用途 |
|----|------|
| `@proj-airi/font-xiaolai` | 小赖；两端 `main.ts` import CSS |
| `@proj-airi/font-cjkfonts-allseto` | 全瀨體；同上 |
| `@proj-airi/font-chillroundm` | 寒蝉半圆；进 `font-cute*` 栈；`stage-ui` 依赖 |
| `@proj-airi/font-departure-mono` | 等宽展示；loading-screens / preset-fonts |
| `@proj-airi/unocss-preset-fonts` | 把本地字体注入 Uno preflight |

**Web**：`apps/stage-web/uno.config.ts` 用 `presetWebFonts('fontsource')` 拉 DM/Nunito 等。
**桌宠**：`renderer/main.ts` 直接 import 全套 `@fontsource-*`（离线窗更稳）。

## 动效分层

### 1. 路由 / 舞台转场 — `ui-transitions`

| 项 | 说明 |
|----|------|
| 包 | `packages/ui-transitions` |
| 组件 | `StageTransitionGroup`、`BubbleWaveOutTransition`、`SlideTransition`、`FantasyFallTransition`… |
| Web | `App.vue` 包 `RouterView`；首页 meta 可写 `stageTransition.name: bubble-wave-out` |
| 桌宠 | 包在 **devDependencies**；主 App **未**挂 `StageTransitionGroup` |
| 演示 | 包 README → Netlify playground |

气质对齐 design-guidelines 里的 **yui540** 舞台转场方向。

### 2. 页面局部 Vue transition — Web styles

`apps/stage-web/src/styles/`：

| 文件 | 内容 |
|------|------|
| `main.css` | 引入 ui + transitions；`:root` / `html.dark`；NProgress（chromatic oklch） |
| `transitions.css` | `.slide-away-*` |
| `vue-transitions.css` | `.fade-*`、左右 slide fade |

桌宠：`apps/stage-tamagotchi/src/renderer/styles/main.css`（进度条色用独立 CSS 变量，非 chromatic NProgress）。

### 3. 弹层 / Overlay — Uno theme.animation

`uno.config.ts` 的 `theme.animation`：`overlayShow/Hide`、`contentShow/Hide`、`slide*AndFade`、`fadeIn/Out`（时长与 `cubic-bezier(0.16, 1, 0.3, 1)`），供 Dialog 等使用。

### 4. 原语内动画 — `packages/ui`

如 `transition-vertical` / `transition-horizontal`、`lamp-flicker` 等；改原语动效先看 `packages/ui/src/components/animations`。

### 5. 加载屏 — `ui-loading-screens`

`LoadingLogoWithBar`、`LoadingSciFiCircle` 等。**当前未接入** stage-web / tamagotchi 运行时（多在 playground / 架构图）；不要当成产品主路径。

## 动态色相动画

两端 `App.vue`：`@property --chromatic-hue` + `.dynamic-hue { animation: hue-anim … }`。用户在配色页打开「动态」后，主色缓慢轮转（见 [色板与主题](./色板与主题.md)）。

## 设计注意

- AGENTS：动画优先查 `apps/stage-web/src/styles`，能复用再新写。
- 新转场优先扩展 `ui-transitions`，避免在业务页散落 keyframes。
- 桌宠透明窗上少做全屏不透明遮罩；已有 loading 用 `bg-*/80` + `backdrop-blur-md`（见桌宠 `index.vue`）。
