# 视觉动捕

## Vision（看图 / 看屏）

路径：`packages/stage-ui/src/stores/modules/vision/`

| 文件 | 职责 |
|------|------|
| `store.ts` | Vision Provider / 模型（localStorage） |
| `orchestrator.ts` | 截帧 → 多模态推理 → 可选经 Channel `context:update` |

这是 **LLM 视觉编排**，不是 Live2D/VRM 渲染。工作负载例：`screen:interpret`（`composables/vision`）。
设置页：`stage-pages/.../modules/vision.vue`。

## Lipsync

| 能力 | 路径 |
|------|------|
| Live2D | `packages/model-driver-lipsync`（`src/live2d`，wlipsync）：音频 → 元音 / mouth-open |
| VRM | `stage-ui-three` 内 lip-sync |
| MMD | `stage-ui-mmd` 内 lip-sync |

通常接在 TTS 播放链之后 → [语音合成](../语音交互/语音合成.md)。

## MediaPipe

`packages/model-driver-mediapipe`：`camera → Tasks Vision → PerceptionState → overlay`。

试玩：`apps/stage-web/src/pages/devtools/model-driver-mediapipe.vue`（及桌宠同类 devtools，若有）。

## Godot sidecar（仅桌宠）

| 层 | 路径 |
|----|------|
| 引擎工程 | `engines/stage-tamagotchi-godot` |
| Electron 宿主 | `apps/stage-tamagotchi/src/main/services/airi/godot-stage` |
| 契约 | `@proj-airi/stage-shared/godot-stage` + 桌面 Eventa |
| UI | `stage-ui/.../model-settings/godot.vue`（experimental） |
| 打包 | electron-builder → `extraResources/godot-stage` |

**只做渲染场景**，不拥有 Agent / 主 IPC。`stageModelRenderer === 'godot'` 时走旁路。
专篇：[Godot旁路](./Godot旁路.md)；场景开关见 [场景组装](./场景组装.md)。

## 阅读顺序

1. Vision：`vision/store.ts` → `orchestrator.ts`
2. Lipsync 包入口
3. MediaPipe + web devtools
4. Godot：引擎 README → 宿主服务
