# 展示模型

## 真源

`packages/stage-ui/src/stores/display-models.ts`

管理用户可选的「身体」资源：预设 URL + 本地导入；按格式拉预览（live2d / three / spine / mmd）。

## 支持格式（`DisplayModelFormat`）

| 枚举 | 值 | 说明 |
|------|-----|------|
| Live2dZip | `live2d-zip` | 主路径 |
| Live2dDirectory | `live2d-directory` | 主路径 |
| VRM | `vrm` | 主路径 |
| SpineZip | `spine-zip` | 实验 |
| PMXZip / PMXDirectory | `pmx-zip` / `pmx-directory` | MMD，实验 |
| PMD | `pmd` | 实验 |

角色卡可通过 `displayModelId` 绑定默认展示模型 → [角色卡片](../角色对话/角色卡片.md)。

## 设置 UI

- 共享：`stage-pages` 下 models 相关页
- 桌宠：exclude 包内 `settings/models/index`，本端覆盖（可含 Godot 控件）→ [启动与配置](../多端应用/桌宠端/启动与配置.md)

## 与 renderer

导入的是**资源**；`stageModelRenderer` 决定用 Live2D 还是 Three 等引擎加载 → [场景组装](./场景组装.md)。

## 阅读顺序

1. `display-models.ts` 格式枚举与导入
2. 设置里模型管理页点一次导入
3. 再进 [Live2D与VRM](./Live2D与VRM.md)
