# 场景组装

> 产品舞台不是渲染包自己「开网页」，而是 `stage-ui` 里按当前 renderer 切换场景。

## 选型真源

| 项 | 路径 |
|----|------|
| 设置 store | `packages/stage-ui/src/stores/settings/stage-model.ts` |
| 类型 | `StageModelRenderer = 'live2d' \| 'vrm' \| 'spine' \| 'mmd' \| 'godot' \| 'disabled'` |
| 组装 | `packages/stage-ui/src/components/scenes/Stage.vue` |

`Stage.vue` 用 `v-if` / 等价分支按 `stageModelRenderer` 挂：

| 值 | 场景组件来源 |
|----|----------------|
| `live2d` | `@proj-airi/stage-ui-live2d` → `Live2DScene` 等 |
| `vrm` | `@proj-airi/stage-ui-three` → `ThreeScene` / VRM |
| `spine` | `@proj-airi/stage-ui-spine` |
| `mmd` | `@proj-airi/stage-ui-mmd` |
| `godot` | 旁路：桌宠 Godot sidecar，不是上述 Vue 场景包主路径 |
| `disabled` | 不渲染角色模型 |

## 壳 vs 场景

| 层 | 包 |
|----|-----|
| Header / InteractiveArea / ChatArea | `stage-layouts` |
| Stage 场景 + TTS/口型挂点 | `stage-ui` `components/scenes` |
| 具体画布 | live2d / three / spine / mmd 包 |

首页如何嵌 Stage：各端自己的 `pages/index`（见多端应用）。

## 与展示模型

`displayModelId` / 导入资源由 [展示模型](./展示模型.md) 管；renderer 类型决定**用哪套引擎加载**该资源。

## 阅读顺序

1. `stage-model.ts`
2. `Stage.vue` 分支
3. 选一条主路径进 [Live2D与VRM](./Live2D与VRM.md)
