# 即时通讯

## 定位

AIRI 相关 IM 接入有两条**不同架构**，选型时先看本表，再进对应目录竖切。

## 对照

| | Discord（Channel 桥） | Telegram / Satori（独立 Agent） |
|--|----------------------|--------------------------------|
| 进程 | `services/discord-bot` | `telegram-bot` / `satori-bot` |
| 智能在哪 | 常把输入送进 **Stage 编排** | **进程内** LLM loop |
| 总线 | Channel Hub（`server-sdk` ↔ `server-runtime`） | 自有 DB/会话；Satori 另接适配上游 |
| 学习文 | `learning/通道机器人/`（含运营 Runbook） | `learning/独立Agent/`（含运营 Runbook） |

## 跟读

1. 用上表选定架构
2. 打开对应目录的学习路径或 Runbook
3. 不要用「装个 bot 就能共用 Stage 记忆」的假设（长期记忆边界见角色对话域）

## 现状

Discord / Telegram / Satori 均可源码启用。

## 边界

- Twitter 自动化不是 IM，见《Twitter服务》。
- 浏览器扩展推上下文不是完整 IM bot。
