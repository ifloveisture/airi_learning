# 浏览器扩展

## 定位

`plugins/airi-plugin-web-extension`：WXT 扩展，抓取 YouTube/Bilibili 等页面与字幕，经 WebSocket（`server-sdk`）推给角色（可含 `spark:notify`）。**Channel 插件**，不是桌宠 ExtensionHost。

## 真源

| 项 | 路径 |
|----|------|
| README | `plugins/airi-plugin-web-extension/README.md` |
| 配置 | `wxt.config.ts` |
| 入口 | `entrypoints/{background,content,popup}/` |
| 事件 | `src/shared/eventa.ts` |

## 跟读

1. README 能力与权限
2. `background` 如何连 `ws://…/ws`
3. content script 抓取点
4. popup 设置项

## 命令

```bash
pnpm -F @proj-airi/airi-plugin-web-extension dev
# 浏览器加载 .wxt/dev；默认 Hub 常为 ws://localhost:6121/ws
# 需本机 Channel Hub：桌宠内嵌或 pnpm dev:server
```

## 现状

可启用。

## 边界

- **不做 STT**：提供「用户在看什么」，听力仍是 Stage Hearing。
- **不是 gamelet**：不走 `extension.airi.json` / ExtensionHost。
- **VS Code 集成**：另一条 `integrations/vscode`，本页不覆盖。
