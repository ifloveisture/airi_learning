# 学习路径 · 世界接入

外围自动化与游戏接入。Discord / Telegram / computer-use 各有独立研究线；本路径只帮你**选型后进对目录**。

## 目标

- 分清：Channel 桥、独立 Agent loop、命令型工具、上下文推送
- 跟完本域竖切（Twitter / 扩展 / VS Code / 游戏表）
- 需要 Bot 或 MCP 时链到正确外域，不混架构

| 你要的 | 走哪 |
|--------|------|
| IM 进 Stage 聊天编排 | Discord + Channel（步骤 2） |
