## Minecraft（进程内认知 + Channel）

| 层 | 路径 |
|----|------|
| 服务 | `services/minecraft`（`@proj-airi/minecraft-bot`） |
| 入口 | `src/main.ts` → `CognitiveEngine({ airiClient })` |
| 认知栈 | `src/cognitive/`：perception / reflex / conscious / action / event-bus |
| Channel | `server-sdk`：`spark:command` / `context:update` / `module:configure` |
| UI 模块 | `packages/stage-ui/.../gaming-minecraft.ts` |

**性质**：本进程有完整四层认知，**同时**经 Channel 挂 Stage —— 不是 Telegram 那种「完全不经 sdk」的独立生命。

**现状**：`services/minecraft/README.md` 有 **Deprecation Notice**（Mineflayer → Fabric / NeoForge 原生 mod）。可本地跑，当历史/过渡样本，不当前进主线。

**为什么迁**（决策来源、安全、外挂 bot vs 原生 mod）→ [Minecraft迁移背景](./Minecraft迁移背景.md)。

## Twitter（自动化，非陪聊 loop）

| 项 | 说明 |
|----|------|
| 路径 | `services/twitter-services` |
| 角色 | Playwright 操作 X；timeline / tweet / user… |
| 接入 | `AiriAdapter`（sdk，模块名 `x`）和/或 `MCPAdapter` |
| 架构笔记 | `services/twitter-services/docs/architecture-20250304.md` |

无自主 `imagineAnAction` 式 tick；偏「命令型工具」。其 MCP 适配器 **≠** [本机操控](../本机操控/) 执行基板。
