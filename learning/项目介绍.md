# Project AIRI 与 `@proj-airi` 介绍

> 读码 / 改功能前的产品与命名入门。架构边界见 [整体架构](./整体架构.md)；已实现能力见 [功能地图](./功能地图.md)；包怎么找见 [共享包图](./共享包图/)。
> 对照：`v0.11.3` · 官方中文总览：https://airi.moeru.ai/docs/zh-Hans/docs/overview/ · 根文案：`docs/README.zh-CN.md`

## 先回答你的问题

**会。** 在本仓继续开发任意一点，迟早会碰到 `@proj-airi/...`。

原因很直接：这是 **pnpm Monorepo**，几乎所有可运行应用与可复用库的 `package.json` `name` 都挂在 **`@proj-airi` 这个 npm scope** 下。你改聊天，会进 `@proj-airi/stage-ui` / `@proj-airi/core-agent`；改 Live2D，会进 `@proj-airi/stage-ui-live2d`；改 Channel Bot，会进 `@proj-airi/server-sdk` / `@proj-airi/discord-bot`；改云端计费，会进 `@proj-airi/server`。命令行也是同一套：

```bash
pnpm -F @proj-airi/stage-web dev
pnpm -F @proj-airi/stage-ui typecheck
```

所以下面这篇同时讲两件事：**产品是谁**，以及 **`@proj-airi` 在工程里到底指什么**。

## 一句话定位

**AIRI（アイリ）= 开源的「数字生命 / AI 虚拟角色容器」。**

官方说法更接近：

> 复刻 Neuro-sama，让 AI waifu / 虚拟角色也能来到我们的世界。

它不是「又一个 Character.ai 式纯聊天页」，而是想把 **大脑（LLM）+ 耳朵（STT/VAD）+ 嘴巴（TTS）+ 身体（Live2D/VRM）+ 外部行动（游戏 / IM / MCP）** 接成一套可自托管、可扩展的系统，让角色能「住」进浏览器、桌面或手机。

对照常见产品：

| 你可能熟悉的 | AIRI 的差异点 |
|--------------|----------------|
| Character.ai / JanitorAI / SillyTavern | 那些强在角色聊天；AIRI 还要身体、语音、桌宠、游戏与工具接入 |
| Neuro-sama | 灵感源头：能直播、玩游戏、互动的 AI VTuber；**不开源**，下播就碰不到 |
| Grok Companion 一类数字陪伴 | 官方文档把自己定位成同类体验的**开源替代方向** |

项目仍在活跃早期：发布版优先保证聊天、角色卡、模型舞台与基础设置；Minecraft / Discord / Telegram / Factorio / 插件宿主 / MCP / computer-use / 完整长期记忆等，往往要**源码配置或单独进程**才能跑。

## `@proj-airi` 到底是什么（三个容易混的名字）

| 名字 | 是什么 | 你开发时怎么用 |
|------|--------|----------------|
| **Project AIRI** / **AIRI** | 产品与本 Monorepo（`moeru-ai/airi`） | 读 `learning/`、改 `apps/` / `packages/` / `services/` |
| **`@proj-airi/*`（npm scope）** | 本仓几乎所有 workspace 包的命名前缀 | `import … from '@proj-airi/stage-ui'`；`pnpm -F @proj-airi/…` |
| **GitHub 组织 [`proj-airi`](https://github.com/proj-airi)** | 从主仓长出来的**卫星仓库**组织 | RAG、记忆、图标、Live2D 工具、awesome 列表等；**不等于**本仓每一个包都在那个 org |

再叠一层组织边界（读 README 时会见到）：

- **`moeru-ai/airi`**：主产品 Monorepo（你现在这个仓）。
- **`@moeru-ai` / `moeru-ai`**：同团队其它基建（如 [`xsai`](https://github.com/moeru-ai/xsai) LLM 客户端生态）。
- **`@moeru/eventa`、`injeca`**：跨进程事件与 DI，被桌宠与插件大量使用，**不是** `@proj-airi` scope，但是同栈硬依赖。

根 `package.json` 自己也叫 `@proj-airi/root`。

## 产品想做成什么样（身体 / 声音 / 上下文 / 行动）

官方 overview 把差异收成四条，开发时对应不同包族：

| 维度 | 用户侧含义 | 仓内大致落点 |
|------|------------|--------------|
| **身体** | Live2D / VRM 等可互动形象 | `stage-ui-live2d` · `stage-ui-three` · 展示模型相关 store |
| **声音** | 能听、能说、知道你在不在说话 | `audio` · `pipelines-audio` · STT/TTS Provider · 云端 speech 路由 |
| **上下文** | 桌面状态、IDE、游戏、插件把环境塞进对话 | Electron 主进程 · ExtensionHost · Channel · VS Code 集成 |
| **行动** | 打游戏、回 Discord/Telegram、MCP 操本机 | `services/*` · `computer-use-mcp` · 各类 bot |

再加上 **可移植性**：从第一天就押 Web 技术（WebGPU / WebAudio / Worker / WASM / WebSocket），所以 Web / Electron / Capacitor 能共用 `stage-ui` 等业务核；需要 TCP、CUDA、系统托盘、窗口穿透的能力再放到桌面或独立服务里，而不是逼所有人只跑浏览器。

## 你能先用到什么（产品面）

| 面 | 包 / 目录 | 适合 |
|----|-----------|------|
| **网页 Stage** | `@proj-airi/stage-web` → https://airi.moeru.ai | 最快上手：配 Provider / Key，聊天 + 舞台 |
| **桌宠 Tamagotchi** | `@proj-airi/stage-tamagotchi`（Electron） | 常驻桌面、穿透、托盘、本地能力、插件宿主 |
| **移动 Pocket** | `@proj-airi/stage-pocket`（Capacitor） | **进行中**；手机上想试优先网页 / PWA |
| **云端 API** | `@proj-airi/server`（`apps/server`） | 账号、聊天同步、计费网关、Official TTS/STT 等 |
| **Channel Hub** | `@proj-airi/server-runtime`（`pnpm dev:server`） | **不是**云端 API；本机模块事件总线 |
| **IM / 游戏 Agent** | `discord-bot` · `telegram-bot` · `minecraft-bot` · … | 源码启用的实验/运营面 |

终端用户配置手册在文档站 `docs/manual/`；本 `learning/` 偏**读码与改点**。

## 为什么改任意一点都会撞上 `@proj-airi`

### 1. 业务几乎都在共享包，不在「某个 .vue 里堆完」

典型分层（只能向下依赖）：

```text
apps（stage-web / tamagotchi / pocket / server…）
  → stage-pages · stage-layouts
    → stage-ui          ← 聊天、设置、角色卡、编排入口大多在这
      → stage-ui-* · core-agent · audio/pipelines · server-sdk*
        → stage-shared · ui · i18n · ccc · stream-kit …
```

你在 `apps/stage-web` 里改一页，import 列表里十有八九是 `@proj-airi/stage-ui/...`。
桌宠多一层 Electron：`@proj-airi/electron-eventa`、主进程 services，以及 `@proj-airi/plugin-sdk`。

### 2. 命令与依赖解析都以 scope 为准

- 过滤包：`pnpm -F @proj-airi/<name> <script>`
- 工作区依赖：`"@proj-airi/stage-ui": "workspace:*"`
- 类型与导出：看该包 `package.json` 的 `exports`，不是随便深层相对路径乱穿

### 3. 「一个用户功能」常常跨多个 `@proj-airi` 包

例：发一句语音聊天

1. UI / 编排：`stage-ui`（chat store）
2. Agent 运行时：`core-agent`
3. 角色卡：`ccc`
4. 音频切段与播控：`pipelines-audio`
5. 若走云端：`server` + `server-sdk-shared` 一类契约
6. 舞台口型 / 模型：`stage-ui-live2d` 或 `stage-ui-three` + `model-driver-*`

所以「只改前端一页」也常要顺着 `@proj-airi` 调用链往下读——[共享包图/最短调用链](./共享包图/最短调用链.md) 就是为这个准备的。

## 仓内 `@proj-airi` 包族速览（开发地图）

不必一次记全；按任务选组即可（细表在 [共享包图/包索引总表](./共享包图/包索引总表.md)）。

| 族 | 代表包 | 改什么时候会碰到 |
|----|--------|------------------|
| Stage 壳与业务核 | `stage-web` · `stage-tamagotchi` · `stage-ui` · `stage-pages` · `stage-layouts` | 任何产品 UI / 设置 / 聊天页 |
| 渲染 | `stage-ui-live2d` · `stage-ui-three` · `stage-ui-spine` · `stage-ui-mmd` | 模型舞台、导入格式 |
| 编排与角色 | `core-agent` · `ccc` · `stream-kit` · `core-character`（空壳） | 对话管线、角色卡、流控 |
| 音频 | `audio` · `pipelines-audio` · `audio-pipelines-transcribe` | VAD/STT/TTS 管线 |
| Channel / 插件 | `server-runtime` · `server-sdk` · `server-shared` · `plugin-sdk` · `plugin-protocol` | Bot、扩展、模块总线 |
| 云端契约 | `server` · `server-schema` · `server-sdk-shared` | Auth、计费、同步、网关 |
| Electron 辅包 | `electron-eventa` · `electron-vueuse` · `electron-screen-capture` | 桌宠 IPC、截屏等 |
| UI / i18n | `ui` · `i18n` · `font-*` · `ui-transitions` | 原语、文案、字体 |
| 服务面 | `discord-bot` · `telegram-bot` · `minecraft-bot` · `computer-use-mcp` · `twitter-services` | 独立进程能力 |

周边还会看到 **不在** `@proj-airi` 下、但同属生态的依赖：`xsai`、`@moeru/eventa`、`@moeru/std`、`injeca`、reka-ui 等——改 Provider / IPC / 错误处理时同样会撞上。

## 边界（避免期待错位）

- **AIRI ≠ 单一 App**：是 Monorepo + 多表面；「能聊天」和「能打 Minecraft」可能是两条完全不同的进程。
- **`pnpm dev:server` ≠ 云端**：前者是 Channel Hub（`server-runtime`），云端是 `apps/server`。
- **`@proj-airi` GitHub org ≠ 本仓全部代码**：主仓在 `moeru-ai/airi`；org 里是更多子项目。
- **空壳 / WIP 包真实存在**：如 `core-character`、`memory-pgvector`、Pocket；见功能地图与薄写清单，不要当成已上线产品能力。
- **无官方代币**：README 明确警告，勿信关联币圈资讯。
