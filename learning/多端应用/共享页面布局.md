# 共享页面布局

> 只讲共享包 **`stage-pages` / `stage-layouts`** 本身。
> 各端如何扫描、exclude、覆盖 → 写在 [网页端](./网页端/)、[桌宠端](./桌宠端/) 各自文章里，本文不展开三端对照实现。

## 真源

| 包 | 路径 | 角色 |
|----|------|------|
| `stage-pages` | `packages/stage-pages/src/pages` | 共享路由页面（settings、providers、modules…） |
| `stage-layouts` | `packages/stage-layouts/src/layouts` | 共享布局壳 |

## 布局名

文件即布局名：`default` · `home` · `stage` · `settings` · `plain`。

页面选用：

```yaml
# <route lang="yaml">
meta:
  layout: settings
```

## 常用组件（stage-layouts）

| 区 | 例子 |
|----|------|
| Layouts | `Header`、`HeaderAvatar`、`InteractiveArea`、`MobileHeader`、`MobileInteractiveArea` |
| Widgets | `ChatArea`、`ChatContainer`、`ChatActionButtons`、`IndicatorMicVolume` |
| Backgrounds | `Provider`、`DialogPicker`、`SakuraPetal`、`default/*` |
| Store | `stores/background.ts` |

`ChatArea` 是发消息 / 语音输入的产品壳（内部调聊天 orchestrator）；Web 侧调用链见 [网页端/聊天与语音路径](./网页端/聊天与语音路径.md)。

## 阅读建议

1. 先扫本页组件与布局名
2. 再回你正在学的那一端：看该端 Vite/`electron.vite` 的 `routesFolder` / `layoutsDirs`
3. 改共享页前，到**对应端**文档确认是否被 exclude
4. 磨砂壳 / 主题色 / 出稿尺：打开 `learning/界面设计/`（设计师向路径 · 视觉规范）
