# 桌宠宿主

> Main 进程：`apps/stage-tamagotchi/src/main/index.ts`

## 启动顺序（摘要）

1. 平台开关（如 Linux/Wayland）· **单实例守卫**（第二实例可早退）
2. `app.whenReady` → 媒体权限 / 文件日志
3. `injeca.provide(...)` 注册整图 → **`injeca.start()`**
4. `emitAppReady` · 调试 / F12 等
5. 退出：`emitAppBeforeQuit` · `injeca.stop` · 刷日志

关闭主窗默认是 **隐藏到托盘**，不等于退出应用。

## injeca provide（按职责）

### 配置 / 宿主

| Key | 职责 |
|-----|------|
| `configs:app` · `configs:artistry` | 应用 / Artistry 配置 |
| `host:electron:app` | Electron `app` |
| `libs:i18n` | 主进程 i18n |

### 模块（AIRI 子系统）

| Key | 路径线索 | 职责 |
|-----|----------|------|
| `modules:channel-server` | `services/airi/channel-server` | 本机 Channel Hub（`server-runtime`；端口常 `SERVER_CHANNEL_PORT` 或 **6121**） |
| `modules:plugin-host` | `services/airi/plugins` | ExtensionHost |
| `modules:mcp-stdio-manager` | `services/airi/mcp-servers` | MCP stdio；配置 `userData/mcp.json` |
| `modules:godot-stage-manager` | `services/airi/godot-stage` | Godot sidecar（WS + 进程） |
| `modules:airi-http-server` | `services/airi/http-server` | 内置 HTTP **壳**；入口现为 `servers: []`（未真正起服务） |

### 窗口 / 壳

| Key | 窗 |
|-----|-----|
| `windows:main` | 主舞台 |
| `windows:settings` · `windows:chat` · `windows:spotlight` | 设置 / 聊天 / 速记条 |
| `windows:caption` · `windows:widgets` · `windows:notice` · `windows:about` | 字幕 / 小组件 / 通知 / 关于 |
| `windows:onboarding` | 首次引导 |
| `windows:beat-sync` | 隐藏音频窗 |
| `windows:devtools:markdown-stress` 等 | 可复用 Devtools 壳 |
| `windows:desktop-overlay` | **仅当** `AIRI_DESKTOP_OVERLAY=1` |
| `app:tray` | 托盘 |

另有 `services:auto-updater` · `services:global-shortcut` · `services:window-auth-manager`。

完整窗口行为见 [窗口地图](./窗口地图.md)。

## Eventa（IPC / RPC 契约）

| 位置 | 内容 |
|------|------|
| `src/shared/eventa/index.ts` | 总表 |
| `src/shared/eventa/plugin/*` | 插件 host / capabilities / tools / assets |
| `main/windows/*/rpc/index.electron.ts` | 各窗绑定 invoke/handlers |
| `main/services/electron/window.ts` | 窗口原语（含 `setIgnoreMouseEvents`） |

模式：契约在 `shared`，实现在 main 服务与各窗 RPC；渲染侧经 preload / Eventa 客户端调用。学习时先打开总表，再跟一条「打开设置 / 开聊天」链路。

## 托盘

`src/main/tray/index.ts`：显示/对齐/缩放主窗，打开 settings / caption / widgets / about / **inlay**，控制 beat-sync 可见性等。

`inlay`（`#/inlay`）由托盘打开，**不在** injeca 的常驻 `windows:*` 启动列表里。

## 全局快捷键 / 更新

| 能力 | 路径 |
|------|------|
| 快捷键服务 | `services/electron/global-shortcut.ts`（及 uiohook 变体） |
| Spotlight 加速键 | `windows/spotlight` + `shared/spotlight-shortcut.ts` |
| 设置 UI | `renderer/pages/settings/system/window-shortcuts.vue` |
| 自动更新 | `services/electron/auto-updater.ts`；About / Settings RPC；`electron-builder.config.ts` |
