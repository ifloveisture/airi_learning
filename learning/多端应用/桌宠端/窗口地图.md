# 窗口地图

> 目录：`apps/stage-tamagotchi/src/main/windows/*`
> 渲染路由多为 Hash：`#/chat`、`#/settings` …

## 总表

| 目录 | 用途 | 典型路由 | 标志 / 备注 |
|------|------|----------|-------------|
| `main/` | 主舞台 | `/`（加载常不带 hash） | 透明 panel · **alwaysOnTop** · 关窗隐藏 |
| `chat/` | 独立聊天窗 | `#/chat` | 普通有框窗 |
| `settings/` | 设置 | `#/settings` | 普通窗；可经 Eventa 导航 |
| `caption/` | 字幕叠层 | `#/caption` | 透明 · alwaysOnTop · 穿透 |
| `spotlight/` | 速记 / 快速 ingest | `#/spotlight` | 透明 · alwaysOnTop · skipTaskbar · 全局快捷键 |
| `widgets/` | 小组件 | `#/widgets?id=` | 透明 + vibrancy · alwaysOnTop |
| `notice/` | 通知对话框 | `#/notice/...` | 引用窗管理 |
| `about/` | 关于 / 更新 | `#/about` | 不可最大化等 |
| `onboarding/` | 首次引导 | `#/onboarding` | 有框（非 mac 叙事） |
| `devtools/` | Devtools 壳 | `#/devtools` 等 | 可复用多键窗口 |
| `beat-sync/` | 隐藏音频 | **`beat-sync.html`** | `show:false`；非 Vue hash 路由 |
| `desktop-overlay/` | grounding 叠层 | `#/desktop-overlay` | 透明 · alwaysOnTop · skipTaskbar · focusable:false · **恒穿透**；`AIRI_DESKTOP_OVERLAY=1` |
| `inlay/` | 托盘 inlay 条 | `#/inlay` | 类 spotlight 配置；**托盘打开**，非 injeca 常驻 |
| `dashboard/` | Dashboard | `#/dashboard` | **代码在，主入口 injeca 未注册** —— 勿当现网窗 |
| `shared/` | 公共配置 | — | `transparentWindowConfig`、导航守卫、显示器几何 |

## 本端壳页（Renderer）

桌宠自管、常与 Web 分叉的页面包括：

`index` · `chat` · `caption` · `spotlight` · `widgets` · `about` · `onboarding` · `notice/*` · `inlay` · `dashboard` · `desktop-overlay*`

设置覆盖见 [启动与配置](./启动与配置.md) 的 exclude 表；另有本端 `settings/system/window-shortcuts.vue`、`modules/mcp.vue`、`developer.vue` 等。

本地 `devtools/` 含：`global-shortcut` · `updater` · `screen-capture` · `vision` · `performance-visualizer` · `widgets-calling` 等；包内其它 shared devtools 仍可能经路由并入。

## 共享 helper

`windows/shared/window.ts`：`transparentWindowConfig()` 等 —— 主舞台 / caption / overlay 的透明与穿透基线多源于此。
