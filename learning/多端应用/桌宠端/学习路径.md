# 学习路径 · 桌宠端

只跟 **Electron 桌宠**。Web 请走 [网页端/学习路径](../网页端/学习路径.md)。

## 目标

- 分清 Main（injeca）与 Renderer（Hash 路由）职责
- 认全多窗口，知道谁管聊天权威、谁只是 follower
- 跟完穿透与（可选）desktop-overlay
- 知道 Channel / MCP / Godot 从哪挂上，细节链到对应域

## 命令

```bash
pnpm install
pnpm dev:tamagotchi
```

可选：`AIRI_DESKTOP_OVERLAY=1` 再开 Overlay；`pnpm -F @proj-airi/stage-tamagotchi smoke:desktop-overlay-live-window`（需 MCP `computer_use`）。
