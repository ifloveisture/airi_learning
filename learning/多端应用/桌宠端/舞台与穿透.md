# 舞台与穿透

> 主舞台渲染：`src/renderer/pages/index.vue`
> 穿透 API：Eventa → `electron.window.setIgnoreMouseEvents`（`main/services/electron/window.ts`）

## 主舞台在做什么

- 路由 `/`：桌宠「角色舞台」主 UI（与 Web 首页同属舞台产品，但 **壳与窗口行为是 Electron 专有**）
- 关窗：主进程侧通常 **hide**，不退出
- 置顶 / 透明 / panel 类型：见 `main/windows/main` + `transparentWindowConfig`

舞台内容（Live2D/VRM、ChatArea 等）仍大量来自 `stage-ui` / `stage-layouts` —— 共享组装见 [共享页面布局](../共享页面布局.md)；本页只关心 **桌宠壳：穿透与叠层**。

## 点击穿透流程

| 步骤 | 位置 |
|------|------|
| 淡出 / 控件岛偏好 | `renderer/stores/controls-island.ts` |
| 悬停淡出与 notice | `controls-island-fade-on-hover` 一类组件 → 可开 `#/notice/fade-on-hover` |
| 命中测试 + 开关穿透 | `pages/index.vue`（像素/Three 透明区域；边框与控件区例外） |
| Caption 穿透 | `main/windows/caption` + `pages/caption.vue` |
| Overlay **始终**穿透 | `desktop-overlay/window-contract.ts`（不抢点击） |

直觉：穿透打开时，鼠标落到「空」舞台区域会点到下层桌面；落到控件 / 非透明命中区则临时关闭穿透以便操作。

## desktop-overlay（实验）

| 项 | 事实 |
|----|------|
| 开关 | `AIRI_DESKTOP_OVERLAY=1`（`isDesktopOverlayEnabled`） |
| 窗 | `main/windows/desktop-overlay` · 路由 `#/desktop-overlay` |
| 数据 | Renderer **轮询** MCP：`computer_use::desktop_get_state`（`desktop-overlay-polling.ts`） |
| 坐标 | `desktop-overlay-coordinates.ts` |
| 烟雾 | `pnpm -F @proj-airi/stage-tamagotchi smoke:desktop-overlay-live-window` |

**不是** Channel 推送；Main 不替 Overlay 推桌面状态。MCP 执行基板与审批语义 → [本机操控](../../本机操控/)。

## 与 Web 对照

| | Web | 桌宠 |
|--|-----|------|
| 舞台页 | 浏览器单页 | 独立置顶透明窗 + 穿透 |
| Overlay / MCP | 无对等主路径 | 可选 Overlay + mcp-stdio-manager |
| 关「首页」 | 关标签页 | 藏托盘 |

更完整的视觉对照 → [界面设计/两端形态差异](../../界面设计/两端形态差异.md)。

## 阅读顺序

1. `main/windows/main` 创建参数
2. `pages/index.vue` 里 `setIgnoreMouseEvents` 相关分支
3. （可选）`desktop-overlay.vue` + polling
4. 审批 / 终端泳道 → [本机操控/宿主接入](../../本机操控/宿主接入.md)
