# 桌宠端 · 备忘

| 点 | 记住 |
|----|------|
| 桌面是 **Electron + injeca** | 不是 Tauri；DI 拼写是 **injeca** |
| 路由 | **Hash**；主窗常无 `#/` |
| stage-pages exclude | 桌面本地有覆盖页，不是功能删了 |
| 关主窗 | 隐藏托盘 ≠ 退出 |
| chat-sync | BroadcastChannel；`/`=authority，`/chat`·`/spotlight`=follower |
| Eventa | 开窗 / 系统能力；不管跨窗聊天气泡 |
| `airi-http-server` | 入口 `servers: []`，别当成已监听的 HTTP 服务 |
| `dashboard` 窗 | 代码在，injeca 未挂 |
| `inlay` | 托盘开，非常驻 provide |
| beat-sync | 独立 HTML，不是 `#/beat-sync` |
| Overlay | `AIRI_DESKTOP_OVERLAY=1` + MCP；恒穿透 |
| Channel 端口 | 常见 6121；根 `pnpm dev:server` 是同族 Hub，桌宠也可内嵌 |
| MCP | `userData/mcp.json`；深读 [本机操控](../../本机操控/) |
| 与 Web | 共享 stage-ui/pages/layouts；壳、多窗、穿透、MCP 仅桌宠 |

命令：`pnpm dev:tamagotchi` · `pnpm -F @proj-airi/stage-tamagotchi typecheck`
