# 桌宠壳能力（Glass · 全屏 · 工具 · MCP）

> 相对「穿透 / 托盘 / 多窗」主叙事，本页补近几轮桌宠壳上的**产品面能力**。
> 真源均在 `apps/stage-tamagotchi`；Kirie（Godot 宿主）见文末一句，不展开。

## 定位

Electron 桌宠除舞台穿透外，还有：原生毛玻璃聊天底、全屏双区实验、天气与 widget 工具、MCP 远程 HTTP。跟读时先认 **Main 窗能力 vs Renderer 工具 store**。

## 1. Native glass（窗底毛玻璃）

| 项 | 路径 / 事实 |
|----|-------------|
| Renderer | `renderer/composables/use-window-backdrop.ts` |
| CSS 钩子 | `window-backdrop.css`；表面标 `data-window-backdrop-surface` |
| 种类 | `inlay` · `panel`（如聊天底） |
| Main | Eventa `electronWindowBackdropUpdate`；包 `@proj-airi/electron-native-backdrop` |
| 相关 | macOS Space 切换时保持 glass（近期修复向） |

产品表现：聊天 / voice inlay 等区域用系统级毛玻璃，而不是纯 CSS `backdrop-blur` 冒充。

跟读：找带 `data-window-backdrop-surface` 的聊天壳 → `useWindowBackdrop` → main backdrop 更新。

## 2. 全屏 Workspace（实验）

| 项 | 路径 / 事实 |
|----|-------------|
| Store | `renderer/stores/fullscreen.ts`（`useFullscreenStore`） |
| 相位 | `closed` → `expanding` → `open` → `closing` |
| 布局 | 角色舞台在左，右侧挂 **surface**（设置 / 聊天等） |
| Surface 注册 | `renderer/components/fullscreen/surfaces.ts` |
| Island UI | `fullscreen-island.vue` |
| 窗上下文 | query `fullscreen-host=main-window` \| `workspace-window`（`window-context.ts`） |
| 草稿交接 | 聊天模式在 legacy / floating / fullscreen 间切换时带走未发草稿（`windows/chat/mode-switch`） |

直觉：不是浏览器 F11；是主窗铺满显示器后，岛上按钮切换右侧面板。面板首次打开后保持挂载，直到退出全屏模式。

现状：**已实现（实验）**；入口以主舞台 / 岛 UI 为准。

## 3. 天气工具与 stage_widgets

| 项 | 路径 / 事实 |
|----|-------------|
| 工具 | `renderer/stores/tools/builtin/weather.ts` → `get_weather` |
| 展示 | 聊天 `weather-tool-call-widget`；也可 `stage_widgets` spawn `weather` |
| Widget 总线 | `stores/tools/builtin/widgets.ts`（`stage_widgets`） |
| 窗 | `main/windows/widgets` · `#/widgets?id=` |
| Devtools | `#/devtools/widgets-calling` |

跟读：开一次天气 tool call → 看 widget；对照 `stage_widgets` schema。

## 4. MCP：stdio + 远程 HTTP

| 项 | 路径 / 事实 |
|----|-------------|
| 配置文件 | `userData/mcp.json`（`mcpServers`） |
| Schema | `shared/mcp-config.ts` · `shared/eventa` 的 `ElectronMcpStdioServerConfig` / `ElectronMcpHttpServerConfig` |
| 管理器 | `main/services/airi/mcp-servers`（模块 key 名仍常叫 mcp-stdio，**已兼 HTTP**） |
| 设置 UI | `renderer/pages/settings/modules/mcp*.vue` |
| HTTP | `url` + 可选 `headers`（常 `Authorization`）；streamable HTTP |

与 computer-use Overlay：仍要本地 stdio MCP + `AIRI_DESKTOP_OVERLAY=1` → [舞台与穿透](./舞台与穿透.md) · [本机操控](../../本机操控/)。

## 边界

- Glass ≠ CSS blur；全屏 Workspace ≠ 仅按系统 F11 全屏。
- MCP HTTP ≠ Channel Hub（`pnpm dev:server`）。
- Kirie ≠ 替换 Electron 主路径的文档默认。
