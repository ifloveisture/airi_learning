# 学习路径 · 网页端

只跟 **`apps/stage-web`**。不要和桌宠/Pocket 混读。

## 目标

- 说明首页每一块 UI 来自哪个包
- 跟完：ChatArea → `ingest`
- 弄清本端 pages 相对 `stage-pages` 多了什么

## 步骤

| # | 读什么 | 文档 |
|---|--------|------|
| 1 | `index.html` + `main.ts` | [启动与配置](./启动与配置.md) |
| 2 | `vite.config.ts` | 同上 |
| 3 | `App.vue` | 同上 |
| 4 | `pages/index.vue` | [首页与舞台](./首页与舞台.md) |
| 5 | 共享包组件（被 Web 引用的部分） | [共享页面布局](../共享页面布局.md) |
| 6 | `Stage.vue` + `chat.ts` | [聊天与语音路径](./聊天与语音路径.md)、[聊天编排](../../角色对话/聊天编排.md) |
| 7 | Web 听写 | [聊天与语音路径](./聊天与语音路径.md)、[听力转写](../../语音交互/听力转写.md) |
| 8 | （可选）设置页 | `stage-pages` 经 Web 路由并入的部分 |

### 从角色卡切入（可选）

若更关心「人设 / Provider / 音色 / 舞台模型如何成套切换」，可先读 [角色卡片](../../角色对话/角色卡片.md)，再回到本路径第 6 步看消息如何进 `ingest`。卡库与设置 UI 在 Web / 桌宠共用；Web 启动时 `App.vue` 会初始化默认卡。

```bash
pnpm install

```
