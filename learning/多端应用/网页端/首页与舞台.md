# 首页与舞台（Web）

## 首页文件

`apps/stage-web/src/pages/index.vue`

- 路由 meta：`layout: stage` → `packages/stage-layouts/src/layouts/stage.vue`（薄包装 `RouterView`）
- **stage-pages 没有对应首页**；Web 舞台首页是本端独有壳

## UI 块从哪来

| 块 | Import |
|----|--------|
| 背景 | `@proj-airi/stage-layouts/components/Backgrounds`（`BackgroundProvider`） |
| Header / MobileHeader | `stage-layouts/.../Layouts/Header.vue` 等 |
| 右侧聊天区 | `InteractiveArea.vue`（内嵌 `ChatArea`） |
| 移动端交互 | `MobileInteractiveArea.vue` |
| 舞台 | `@proj-airi/stage-ui/components/scenes` → `WidgetStage`、`ViewControlSlider` |

背景主题：`stage-layouts/stores/background`、`composables/theme-color`。

## Live2D / VRM 真正画在哪

首页只挂 `WidgetStage`。分支在：

`packages/stage-ui/src/components/scenes/Stage.vue`

| `stageModelRenderer` | 组件 | 包 |
|----------------------|------|-----|
| `live2d` | `Live2DScene` | `@proj-airi/stage-ui-live2d` |
| `vrm` | `ThreeScene` | `@proj-airi/stage-ui-three` |
| `spine` / `mmd` / `godot` | 对应场景 | 实验 / 桌面向 |

导出：`packages/stage-ui/src/components/scenes/index.ts`（`WidgetStage` = `Stage.vue`）。

TTS 自动朗读、口型相关钩子也挂在 `Stage.vue`（见 [语音合成](../../语音交互/语音合成.md)）。

## 本端 vs 共享页面

**本端多出（`apps/stage-web/src/pages`）：**

- `index.vue` 舞台首页
- `auth/*` 登录
- `settings/characters/**` 角色管理 UI
- `settings/account`（包装 stage-pages 组件）
- `settings/system` 入口 + `developer.vue`
- 一批 Web 专用 `devtools/*`（录音、抠图、MediaPipe、performance…）

**共享并入（`packages/stage-pages`）：** 大量 `settings/**`、共享 `devtools/**`（context-flow、websocket-inspector…）。

## 本端特有 store / composable

| 文件 | 性质 |
|------|------|
| `src/stores/pwa.ts` | PWA 更新提示 |
| `src/stores/devtools-lag.ts` | FPS / longtask，供性能浮层 |
| `src/stores/background.ts` | 再导出 layouts 的 background |
| `src/composables/audio-*` | Devtools 向简易麦克风；正式听写走 stage-ui |
| `src/composables/perf/*` | 配合 lag sampler |

业务 Pinia（chat、hearing、providers…）**全部在 stage-ui**，Web 不另起炉灶。

## 依赖方向（牢记）

```text
stage-web
  → stage-layouts（壳、ChatArea、布局）
  → stage-pages（设置页路由）
  → stage-ui（业务 + WidgetStage）
  → stage-ui-live2d / stage-ui-three
```

layouts / pages → stage-ui；**绝不**反向依赖 `apps/stage-web`。

视觉气质与主题色链路 → [界面设计](../../界面设计/)。
