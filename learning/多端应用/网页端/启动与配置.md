# 启动与配置（Web）

## 入口

| 文件 | 作用 |
|------|------|
| `apps/stage-web/index.html` | `#app`；预载 Live2D Cubism Core |
| `apps/stage-web/src/main.ts` | 创建 app、挂插件、mount |
| `apps/stage-web/src/App.vue` | 全局初始化 + `RouterView` 壳 |
| `apps/stage-web/vite.config.ts` | 路由双源、alias、PWA、资源下载 |

## `main.ts` 插件顺序

1. 样式（字体、reset、UnoCSS、`main.css`…）
2. `createPinia()`
3. `setupLayouts(routes)` ← `vue-router/auto-routes` + `virtual:generated-layouts`
4. History：默认 `createWebHistory`；`VITE_APP_TARGET_HUGGINGFACE_SPACE` 时用 Hash
5. NProgress：`beforeEach` / `afterEach`
6. `createApp(App)` 依次：`MotionPlugin` → `autoAnimatePlugin` → `router` → `pinia` → `PiniaColada` → `i18n`（`src/modules/i18n.ts`）→ `Tres`
7. `app.mount('#app')`

DEV 下另有 MutationObserver，缓解 Vue DevTools 与 Reka UI `DismissableLayer` 的 pointer-events 冲突。

## `App.vue` 启动时初始化（节选）

在 `onMounted` 一带会拉起（均来自 stage-ui 或本端）：

- 本端 `usePWAStore()`（`src/stores/pwa.ts`）
- `useAuthProviderSync`、analytics、displayModels、airi-card、onboarding
- chatSession、serverChannel、contextBridge、characterOrchestrator、stageModel、audioDevice
- `useInferencePreload`

模板：`StageTransitionGroup` → `RouterView` + `ErrorBoundary`；`ToasterRoot`；`OnboardingDialog`；本端 `PerformanceOverlay`。

## Vite：路由与布局

```text
routesFolder:
  apps/stage-web/src/pages
  packages/stage-pages/src/pages

layoutsDirs:
  apps/stage-web/src/layouts     # 当前为空
  packages/stage-layouts/src/layouts   # 实际布局真源
```

布局名：`default` / `home` / `plain` / `settings` / `stage`。页面用 `<route lang="yaml"> meta.layout` 选择。

## Vite：源码 alias（开发直链）

| alias | 指向 |
|-------|------|
| `@proj-airi/stage-ui` | `packages/stage-ui/src` |
| `@proj-airi/stage-layouts` | `packages/stage-layouts/src` |
| `@proj-airi/stage-pages` | `packages/stage-pages/src` |
| `@proj-airi/stage-shared` | `packages/stage-shared/src` |
| `@proj-airi/server-sdk` | `packages/server-sdk/src` |
| `@proj-airi/i18n` | `packages/i18n/src` |

改共享包源码后热更即可，不必先 build packages（与生产 `workspace:` 消费不同）。

## 关键插件

| 插件 | 作用 |
|------|------|
| `vue-router/vite` | 文件系统路由 → `typed-router.d.ts` |
| `vite-plugin-vue-layouts` | 布局 |
| `vite-plugin-pwa` | PWA（HF Space 可关；dev 不注册 SW 但仍需插件因 `virtual:pwa-register`） |
| `unocss/vite` | `apps/stage-web/uno.config.ts` |
| Live2D/VRM Download 插件 | 资源落到 `stage-ui` assets |
| mkcert | `pnpm dev:web:https` 或 `--mkcert` |

## 命令

```bash
pnpm install
pnpm dev            # 默认即 stage-web
pnpm dev:web
pnpm dev:web:https
pnpm build:web
pnpm -F @proj-airi/stage-web typecheck
```
