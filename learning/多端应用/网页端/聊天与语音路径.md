# 聊天与语音路径（Web）

Web 上聊天与听写的**产品路径**都汇聚到 `useChatOrchestratorStore().ingest`，但入口有多条。

## 文字发送

```text
InteractiveArea.vue
  └─ ChatArea.vue
       handleSend()
         → providersStore.getProviderInstance(activeProvider)
         → useChatOrchestratorStore().ingest(text, { chatProvider, model, providerConfig })
              └─ packages/stage-ui/src/stores/chat.ts
                   └─ core-agent runtime.ingest(...)
```

| 文件 | 角色 |
|------|------|
| `packages/stage-layouts/.../InteractiveArea.vue` | 桌面布局右栏 |
| `packages/stage-layouts/.../ChatArea.vue` | 输入框、发送、麦克风 Popover |
| `packages/stage-layouts/.../MobileInteractiveArea.vue` | 移动端同样 `ingest` |
| `packages/stage-ui/src/stores/chat.ts` | 编排入口 |
| scenarios `ChatHistory` 等 | 气泡与会话抽屉 |

模型来自 `useConsciousnessStore` 的 active provider/model。细节见 [聊天编排](../../角色对话/聊天编排.md)。

## 语音输入：两条路径

### A. 流式（ChatArea · 主交互）

```text
麦克风 / HearingConfig
  → useTranscriptions（stage-layouts/composables/use-transcriptions.ts）
       → useHearingSpeechInputPipeline().transcribeForMediaStream
            → hearing store（Web 默认可自动配 browser-web-speech-api）
       → 写入 messageInput，可选 autoSend → handleSend → ingest
```

未配置 STT provider 时，Web 会尝试浏览器 Web Speech；Electron 路径会排除该策略。

### B. 非流式 VAD 段录音（首页 `index.vue`）

```text
settingsAudioDevice.enabled
  → useVAD（worklet 来自 stage-ui/workers/vad）
  → useAudioRecorder 起停
  → onStopRecord → transcribeForRecording(blob)
  → chatStore.ingest(text, …)
```

当 provider **支持流式输入**时，首页会关掉自动录音，避免与路径 A 双开。

### 对照

| 场景 | 入口 | 转写 | 发送 |
|------|------|------|------|
| 输入框旁流式麦 | ChatArea + `useTranscriptions` | `transcribeForMediaStream` | `ingest` / autoSend |
| VAD 切段 | `pages/index.vue` | `transcribeForRecording` | `ingest` |

配置页（共享）：`/settings/modules/hearing`、`/settings/providers/transcription/*`。

## TTS 输出（舞台）

回复朗读不在 ChatArea，而在 `Stage.vue`：订阅编排 token 钩子 → `createSpeechPipeline` → TTS provider。见 [语音合成](../../语音交互/语音合成.md)。

## 建议动手验证

1. `pnpm dev:web`，配好一个 LLM provider
2. 打字发送，在 Vue DevTools 看 `chat-orchestrator` / `chat-session`
3. 开麦克风流式，确认走 `useTranscriptions`
4. 关流式、开音频设备，看首页 VAD 是否切段 ingest
