# Web 舞台

## 启动

`apps/stage-web/src/main.ts`：

- `createApp(App).use(router).use(pinia)…`
- 路由来自 `vue-router/auto-routes`，经 `setupLayouts`（`virtual:generated-layouts`）
- 默认 `createWebHistory`；部分托管环境（如 HF Space）用 Hash

命令：`pnpm dev` / `pnpm dev:web`。

## 路由合并

配置：`apps/stage-web/vite.config.ts`

- `routesFolder`：本端 `src/pages` + `packages/stage-pages/src/pages`（全量）
- `layoutsDirs`：共享 `packages/stage-layouts/src/layouts`（本端通常无 `src/layouts`）

页面用 frontmatter 选布局，例如：

```yaml
meta:
  layout: settings
```

## 首页组装

常见直接引用：

- `@proj-airi/stage-layouts` 的 `Header`、`InteractiveArea` 等
- `@proj-airi/stage-ui` 场景与 store
- Live2D / Three 渲染包

## 阅读顺序

1. `main.ts` + `App.vue`
2. `vite.config.ts` 的 routesFolder / layoutsDirs
3. `src/pages/index`（或等价首页）如何拼 ChatArea 与舞台
