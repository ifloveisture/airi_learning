# 边界与定位

> 包内原话：AIRI = 控制面；`computer-use-mcp` = 本机执行与 workflow 基板。

## 一句话

```text
Stage（规划 / 聊天 / 审批 UX / Provider / MCP 附着）
        │  MCP stdio
        ▼
computer-use-mcp（观察 · 选表面 · 确定性执行 · 审计 / Trace）
```

**不**自带「陪聊式」`imagineAnAction` tick；价值在编排与可观测执行，不在单独点鼠标。

## 与其它 services 对照

| | Channel Bot（Discord） | 独立 Agent（TG/Satori） | **本机操控（本域）** | Minecraft |
|--|------------------------|-------------------------|----------------------|-----------|
| 传输 | Channel（`server-sdk`） | 无 sdk | **MCP stdio** | Channel + 认知栈 |
| 认知 / 规划 | Stage | 本进程 LLM loop | **Stage** | 本进程四层 + Stage |
| 本包角色 | 感官/执行器 | 整段生命 | **执行基板** | 游戏认知 |
| 学习域 | [通道机器人](../通道机器人/) | [独立Agent](../独立Agent/) | **本域** | [世界接入](../世界接入/) |

总表仍见 [独立Agent/services全景](../独立Agent/services全景.md)。

## 执行器模式（v1）

| 模式 | 含义 |
|------|------|
| `dry-run` | 默认；不注入输入；仍可截图调试 |
| `macos-local` | **当前主后端**：窗口观察 + Swift/Quartz 注入 |
| `linux-x11` | 遗留实验，非 v1 主叙事 |

环境变量入口：`COMPUTER_USE_EXECUTOR` 等，详见包 `README.md`。

## 工具面分层（记结构即可）

| 层 | 代表工具 | 学习含义 |
|----|----------|----------|
| Desktop | `desktop_observe_*` / click / type… | 坐标 UI；审批更严 |
| Terminal | `terminal_exec` · PTY 族 | **当前产品主线** → [终端泳道](./终端泳道.md) |
| Browser DOM | `browser_dom_*` | 与盲点坐标分流 |
| Workflow | `workflow_*` | 可重复任务，非一次性 demo |
| Approval / Trace | `desktop_*_pending_*` · session trace | 控制面契约 |

优先序（包定位）：**工具 / 终端 / workflow 确定性路径** > 纯视觉坐标回放。

## 策略边界（macOS v1 摘要）

- 终端命令、开/聚焦 App：**总是要审批**
- click/type/press/scroll：按次审批（`COMPUTER_USE_APPROVAL_MODE`）
- `denyApps` 仍挡敏感前台（默认含 AIRI 自身，防自操作）
- `COMPUTER_USE_OPENABLE_APPS` 只闸 open/focus

细节以包 `README.md` Policy 与 `AGENTS.md` 为准；变了以后者 handoff 为准。
