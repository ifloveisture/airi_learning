# 频次数据

## 定位

本域 `packages/` 使用频率的**落盘结果**与扫描脚本；只服务「包索引总表」排序，不导出到域外工具链。

## 真源

| 路径 | 角色 |
|------|------|
| `freq-scan.mjs` | 只读仓源码；写入 `_data/freq-latest.json` |
| `_data/freq-latest.json` | 最近一次扫描的 `meta` + `rows` |

## 计量（与总表一致）

| 字段 | 含义 |
|------|------|
| `depConsumers` | workspace `package.json` 直接依赖次数 |
| `files` | 触及文件数 |
| `importHits` | 包名或 `packages/<dir>` 命中次数 |
| `score` | `dep*100 + files*3 + min(hits,400)` |

不扫描 `learning/`，避免笔记抬分。不改仓内其它文件、不装依赖。

## 现状

最近抽样见 `_data/freq-latest.json` → `meta.scannedAt`（写入总表「频次怎么算」时同步改日期）。

## 边界

| 是 | 不是 |
|----|------|
| 本域维护用数据 | CI / turbo / 根 package scripts |
| Agent 按需重跑后改总表 | 读者日常操作步骤 |
