## 怎么用

### Three / VRM

包 README 已写清生命周期。典型消费：

```ts
import { ThreeScene, useModelStore } from '@proj-airi/stage-ui-three'
// 诊断：@proj-airi/stage-ui-three/trace
// VRM 辅助：@proj-airi/stage-ui-three/composables/vrm
```

注意：`scenePhase` / `sceneMutationLocked` 未 mounted 前不要强行改轨道控制器；换模走包内 cache/`scopeKey` 语义，勿自己乱 dispose。

### Live2D / Spine / MMD

- 从对应包 `src/index.ts` 导出的场景组件与 stores 接入
- 产品侧通常经 `stage-ui` 的 scenes / display-model 选择，而不是页面里手搓 WebGL
- MMD：跟包内 README「How to use」
- Spine：桌宠 pages 引用更全，Web 可能较少

### 口型与动捕

| 包 | 用法要点 |
|----|----------|
| `model-driver-lipsync` | 音频 → 元音权重 → Live2D；由 stage-ui 管线挂，很少单独在页面 new |
| `model-driver-mediapipe` | 实验；Web **devtools** 动捕页可试 |
