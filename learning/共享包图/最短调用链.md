# 最短调用链

## 定位

从端到包的稳定关节点：**聊天**、**Channel**、**路由**、**语音**、**角色表现切段**。对照源码用；完整时序见功能域。

按任务找文件 → [任务速查](./任务速查.md)。

## 链 A · 发聊天

```text
apps/stage-web/src/pages/index.vue
  → useChatOrchestratorStore()     @proj-airi/stage-ui/stores/chat
  → useProvidersStore()            @proj-airi/stage-ui/stores/providers
       │
       ├─ createChatOrchestratorRuntime()   @proj-airi/core-agent
       ├─ useChatSessionStore()             stores/chat/session-store
       ├─ useChatContextStore()             stores/chat/context-store
       │      └─ createContextRegistry()    @proj-airi/core-agent
       └─ useLLM() / streamFrom             stores/llm.ts → @proj-airi/core-agent
```

- 角色卡：`stores/modules/airi-card.ts` → `@proj-airi/ccc`。
- 回复出口播控 / 切段 → **链 D / E**。

### 链 A′ · 云同步（不是 Channel）

```text
stores/chat/session-store.ts
  → createChatWsClient()           libs/chat-sync/ws-client.ts
  → @proj-airi/server-sdk-shared   （newMessages / pullMessages / sendMessages）
  → 云端 apps/server（HTTP + WS）
```

与链 B 的 `@proj-airi/server-sdk` **Client** 无关。

## 链 B · Channel 模块总线

```text
pnpm dev:server
  → @proj-airi/server-runtime          Hub

apps/stage-web/src/App.vue
  → useModsServerChannelStore()
       @proj-airi/stage-ui/stores/mods/api/channel-server.ts
         → new Client({ ... })         @proj-airi/server-sdk
         → createTextProtocolConnector
         → onEvent / send*

类型：
  @proj-airi/server-sdk 的 WebSocketEvents
  更底层：plugin-protocol → server-shared
```

桌宠可内嵌 `server-runtime`。插件 Host：

```text
桌宠 main plugins
  → @proj-airi/plugin-sdk（+ 可选 plugin-sdk-tamagotchi）
样例：apps/stage-tamagotchi/.../plugins/examples/
```

## 链 C · 共享页进路由

```text
apps/stage-web/vite.config.ts
  routesFolder  += packages/stage-pages/src/pages
  layoutsDirs   += packages/stage-layouts/src/layouts

页面内：
  @proj-airi/stage-ui/stores/…
  @proj-airi/stage-layouts/components/…
```

桌宠同理，看 `electron.vite.config`。

## 链 D · 语音播控与口型

```text
听力（进）：
  useHearingStore / useHearingSpeechInputPipeline
    @proj-airi/stage-ui/stores/modules/hearing.ts
    → 转写 Provider → 文本可再进链 A

播控（出）：
  packages/stage-ui/src/components/scenes/Stage.vue
    → createPlaybackManager()          @proj-airi/pipelines-audio
    → createSpeechPipeline()           @proj-airi/pipelines-audio
    → useSpeechStore()                 stores/modules/speech.ts
    → useSpeechRuntimeStore().registerHost(pipeline)
         stores/speech-runtime
         （services/speech/pipeline-runtime.ts）
    → createLive2DLipSync()            @proj-airi/model-driver-lipsync
    → 角色 IntentHandle                stores/character
         （类型来自 pipelines-audio）

底层：
  @proj-airi/audio
  @proj-airi/pipelines-audio
  @proj-airi/stream-kit                Stage.vue / composables/queues 里 createQueue
```

流控解析：`stores/llm-streaming-control.ts` → `createStreamingControlParser`。

## 链 E · 角色表现切段（今日路径）

> **`@proj-airi/core-character` 当前是空壳**（`src/index.ts` 仅 `export {}`）。
> `stage-ui` 虽声明依赖，**不要** import 它期望切段/情绪/TTS 行为。
> 今日切段与播控在 **pipelines-audio + Stage/tts-session**。

```text
LLM / 编排出口（链 A）
  → 文本进入 speech 意图
       stores/character（IntentHandle）
       libs/speech/tts-session.ts（segmenter / emotion 特殊标记）
  → createSpeechPipeline
       @proj-airi/pipelines-audio
         processors/tts-chunker.ts     （Intl.Segmenter 等切块）
         managers/playback-manager
  → Stage.vue 注册 pipeline + 口型（链 D）

规划位（未实现）：
  packages/core-character              ← 空；将来角色表现管线
```

调「何时切段 / 队列作废」等**常数**：算法主线学习域；实现落点在 pipelines-audio 与 stage-ui speech，不在 core-character。

## 边界

| 是 | 不是 |
|----|------|
| 入口与包边界 | 完整时序 / 错误码 / 算法常数全文 |
| Channel ≠ 云同步 ≠ 插件 Host | 云端 Hono 路由细节（`apps/server`） |
| 链 E = 今日表现路径 | 把空壳 `core-character` 当实现 |
