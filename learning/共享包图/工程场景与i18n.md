## 怎么用

### i18n

1. **只**在 `packages/i18n` 增改文案键（词条是 YAML；语种 `index.ts` 只做拼装）
2. 端与 stage-* 通过 vue-i18n / 包导出消费
3. Crowdin 与「为何用 YAML 而非 JS 语言包」见工程横切《文案与Crowdin》
4. 验证：`pnpm dev:web` 切语言，或 Histoire（部分故事跟 locale）

### cap-vite（Pocket）

```bash
pnpm exec cap-vite -- ios --target <DEVICE_OR_SIM>
pnpm exec cap-vite -- --host 0.0.0.0 --port 5173 -- android --target <ID>
# 或
pnpm -F @proj-airi/stage-pocket run dev:ios -- --target <ID>
```

设备列表：`pnpm exec cap run ios --list` / `android --list`。细节见包 README。

### Vishot 场景

Electron 侧定义场景 → 抓 raw → browser 包合成文档图：

```bash
pnpm -F @proj-airi/stage-tamagotchi build
pnpm capture:tamagotchi
# 或按 scenarios-*-browser README 的 capture 路由参数
```

写新场景：跟 `scenarios-stage-tamagotchi-electron` README「Scenario Authoring」。
