# 音频与听写管线

## 定位

听力 / 语音的**库层**：底层 `audio`、共享编排 `pipelines-audio`、转写前文件转流辅助。UI 与设备权限在端和 `stage-ui`；本组提供可复用策略与工具。

## 怎么用

### 选包

| 需求 | 用 |
|------|-----|
| AudioContext、编码工具 | `@proj-airi/audio` |
| 播控、流控事件、ASR 碎片缓冲 | `@proj-airi/pipelines-audio` |
| 本地音频文件 → `MediaStream` 再送转写 | `@proj-airi/audio-pipelines-transcribe` |
| Vue 生命周期 / 麦权限 UI | **不要**放这里 → stage-ui / 端 |

### 管线示例（官方 README）

```ts
import { createTranscriptBuffer } from '@proj-airi/pipelines-audio'

const buffer = createTranscriptBuffer({
  flushDelayMs: 1200,
  flush: async text => sendToChat(text),
})

buffer.push('hello')
buffer.push('world')
await buffer.dispose()
```

其它：managers（采集/播放调度）、processors、llm-streaming-control —— 按目录名找，被 `core-agent` / `stage-ui` 引用。

### 在产品里怎么「用到」

1. 跟 [最短调用链](./最短调用链.md) · 链 D：`Stage.vue` / `hearing.ts` / `speech.ts`
2. Web/桌宠开语音权限；devtools 音频页可观察电平类控件
3. 改缓冲策略：跟 `createTranscriptBuffer` 或 pipelines managers，不要只改 UI 仪表盘组件
4. 口型：同链 D → `model-driver-lipsync`（渲染组）
