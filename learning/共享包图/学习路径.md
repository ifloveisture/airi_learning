# 学习路径 · 共享包图

## 目标

按组认清高频包；日常改功能时先用**任务速查**落到文件，再用**最短调用链**认边界。

## 步骤（域内）

| # | 读什么 |
|---|--------|
| 1 | [任务速查](./任务速查.md)（开发查阅优先） |
| 2 | [最短调用链](./最短调用链.md)（A / A′ / B / C / D / E） |
| 3 | [包索引总表](./包索引总表.md)（频次 + Top 15） |
| 4 | [演示与用例入口](./演示与用例入口.md) |

组文顺序：Stage壳 → 渲染 → UI → 编排 → 音频 → Channel → 云端 → Electron → 工程 → 迁出。

## 最短动手

```bash
pnpm dev:ui
pnpm dev:web
pnpm dev:server
```

## 边界

- **本路径**：导航、怎么用、演示。
- **业务竖切**：各功能域；本域少链外域。
