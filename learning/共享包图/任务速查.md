# 任务速查

## 定位

日常开发「我要改 X，先打开哪」——**任务 → 包 → 入口**。细逻辑仍下钻源码或功能域；本表只导航。

路径相对仓库根。对照 `v0.11.3`。端到包时序见 [最短调用链](./最短调用链.md)（链 A～E，含 A′ 云同步）。
