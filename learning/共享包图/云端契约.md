# 云端契约

## 定位

与 Channel **正交**的云端面：`apps/server` 的 **schema** 与前后端 **共享事件/类型**。你会用 = 改登录/同步/计费相关类型时找对包，并在起云端后走产品登录路径验证。

## 怎么用

### `server-schema`

- 只被 **`apps/server`** 作为 DB/迁移表面消费
- 用法：在 server 应用内 import schema、跑迁移；**不要**在浏览器直接依赖整棵 schema
- 跟读 server 的 db 入口如何引用本包

### `server-sdk-shared`

- `apps/server` 与 **`stage-ui`** 共用契约（聊天同步等 WS/事件形状）
- 前端：`libs/chat-sync` + `session-store`（[最短调用链](./最短调用链.md) · **链 A′**）
- 改事件字段：先改 shared，再改 server handler 与 stage-ui 消费者（保持同版本语义）
- **不是** Channel 的 `@proj-airi/server-sdk` Client（那是链 B）

### 和 Channel 的 `server-sdk` 区分

| 包 | 连什么 |
|----|--------|
| `@proj-airi/server-sdk` | 模块 Channel Hub |
| `@proj-airi/server-sdk-shared` | 云端 API/WS 契约碎片 |
| `@proj-airi/server-schema` | 云端数据库 |
