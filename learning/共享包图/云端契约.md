# 云端契约

## 定位

与 Channel **正交**的云端面：**API 库迁移**与前后端 **共享事件/类型**。改登录/同步/计费相关类型时找对包，并在起 Auth+API 后走产品登录路径验证。

旧 `apps/server` / `packages/server-schema` **已迁**：迁移在 `server/apps/api/drizzle/`，共享契约在 `server/packages/server-sdk-shared`（npm 名以 package.json 为准）。

## 真源

| 目录 | npm（约） | 入口 |
|------|-----------|------|
| `server/packages/server-sdk-shared` | `@proj-airi/server-sdk-shared` | 共享事件/类型 |
| `server/apps/api/drizzle` + `src/schemas` | （API 包内） | Drizzle 迁移与表 |
| `server/packages/auth-shared` | `@proj-airi/auth-shared` | Auth 共享 schema |

## 怎么用

### API drizzle / schemas

- 只被 **`@proj-airi/api-server`** 作为 DB/迁移表面消费
- **不要**在浏览器直接依赖整棵 schema
- 跟读 API 的 db 入口如何加载 `drizzle/`

### `server-sdk-shared`

- API 与 **`stage-ui`** 共用契约（聊天同步等 WS/事件形状）
- 前端：`libs/chat-sync` + `session-store`（[最短调用链](./最短调用链.md) · **链 A′**）
- 改事件字段：先改 shared，再改 API handler 与 stage-ui 消费者
- **不是** Channel 的 `@proj-airi/server-sdk` Client（那是链 B）

### 和 Channel 的 `server-sdk` 区分

| 包 | 连什么 |
|----|--------|
| `@proj-airi/server-sdk` | 模块 Channel Hub |
| `@proj-airi/server-sdk-shared` | 云端 API/WS 契约碎片 |
| API drizzle | 云端业务数据库 |
