## 怎么用

### 角色卡 `ccc`

```ts
import { /* define / export 以包导出为准 */ } from '@proj-airi/ccc'
```

实操：产品里走导入/导出角色卡；跟读 `ccc/src/define`、`export` 与 `stage-ui/stores/modules/airi-card.ts`。

### `stream-kit`

队列工具。调用方示例：`stage-ui/composables/queues.ts`、`Stage.vue` 的 `createQueue`。不要在页面里无故直接 new；改播控队列时沿调用方上追。

### `core-agent`

主消费者 `stage-ui`：

- `stores/chat.ts` → `createChatOrchestratorRuntime`
- `stores/chat/context-store.ts` → `createContextRegistry`
- `stores/llm.ts` → `streamFrom` 等

验证：`pnpm -F @proj-airi/core-agent exec vitest run`。不要在业务页直接拼一整套 runtime，除非写新宿主。

### `core-character`（空壳）

| 今天 | 不要做 |
|------|--------|
| 打开 `packages/core-character/src/index.ts` 确认仍是 `export {}` | `import` 后指望切段/情绪/TTS |
| 切段/播控走链 E（pipelines-audio + tts-session + Stage） | 把包描述当已实现文档 |

`stage-ui/package.json` 仍有 workspace 依赖，属占位，无运行时导出可用。

### `memory-pgvector`

进行中空壳；依赖 `server-sdk` 形态。产品面未闭合前只认边界。
