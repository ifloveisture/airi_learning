## 常用命令

```bash
pnpm install
pnpm dev:web
pnpm dev:tamagotchi
pnpm -F @proj-airi/server dev    # 云端 API
pnpm dev:server                  # Channel Hub（不是云端）
pnpm -F @proj-airi/discord-bot start
```
