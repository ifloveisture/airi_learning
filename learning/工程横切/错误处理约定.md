# 错误处理约定

## 定位

TypeScript 侧统一取错误文案与注释标记，避免各包自造 `error instanceof Error ? …`。

## 真源

| 项 | 说明 |
|----|------|
| 取消息 | `@moeru/std` 的 `errorMessageFrom(error)`（可 `?? 'fallback'`） |
| 规范 | 根 `AGENTS.md` |
| 规避注释 | `// NOTICE:`（原因、根因、来源、删除条件）· `TODO` / `REVIEW` |

## 跟读

1. 在已有代码里搜 `errorMessageFrom` 看用法
2. 新 catch 路径改用同一 helper
3. 临时 workaround 必须写完整 `NOTICE` 块（见 AGENTS 模板）

## 现状

约定已落地；历史代码可能仍有手写分支，改到时替换。

## 边界

- **用户可见 toast**：仍走 i18n 文案，不要把 raw stack 抛到 UI。
- **服务端 HTTP 错误形状**：看 `apps/server` 路由与 ai-context，不单靠本页。
