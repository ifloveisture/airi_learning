# 语音合成

## 配置面

`packages/stage-ui/src/stores/modules/speech.ts`（`useSpeechStore`）：

- `activeSpeechProvider` / `activeSpeechModel` / `activeSpeechVoiceId`
- 可被角色卡覆盖 → [角色卡片](../角色对话/角色卡片.md)
- 手动试听：`speech(...)` → `@xsai/generate-speech`
- `speech-noop`：舞台 TTS 直接空返回（不发音）

设置页：`stage-pages/.../modules/speech.vue`。

| 类型 | 路径线索 | 说明 |
|------|----------|------|

## 聊天自动朗读

主挂点：`packages/stage-ui/src/components/scenes/Stage.vue`（编排钩子，不在 ChatArea 输入框逻辑里）。

1. `onBeforeMessageComposed` → 若本回合 `speaks` → `voice.startResponse`（开朗读响应）
2. `onTokenLiteral` → 未静音则 `voice.getSpeech(context)?.write(literal)`
3. `onStreamEnd` / `onAssistantResponseEnd` → `voice.finishResponse`
4. 管线：`createSpeechPipeline` + `speechRuntimeStore.registerHost`
5. TTS 回调内 `getProviderInstance(activeSpeechProvider)` → `generateSpeech` 或双向 WS

相关：

- `stores/speech-runtime.ts` — intent（`openIntent`）
- `services/speech/pipeline-runtime.ts`
- 角色旁白：`stores/character` 的 `emitTextOutput`

口型接在播放后 → [视觉动捕](../舞台呈现/视觉动捕.md)。

## 何时开 TTS / 何时不读（读码前印象）

| 情况 | 会不会朗读 | 说明 |
|------|------------|------|
| 普通前台助手回合且 `context.speaks` | 会开响应，再按 token 写语音 | Stage 钩子入口；`holdsVoice` 看 `speaks` |
| 后台任务 / 明确 `speaks: false` | 不开 | 注释约定：只有「说话的回复」驱动 speech |
| `speechMuted` | 字面 token 不写 TTS；特殊 token 可走静音分支 | 用户静音与「无 Provider」不同 |
| Provider = `speech-noop`（默认值之一） | 合成空返回，听不到声 | 仍可能走 session / 管线钩子；调试时先看选型 |
| 未配可用 Speech Provider / Key | 试听或自动朗读失败或无声 | 设置页 Speech；Official 还要登录与计费 |
| 取消回合 / 宿主卸麦 | 播放收束或 cancel | Voice 对 abort / detach 会 cancel turn 与 speech |

手动试听走 `speech.ts` 的 `speech(...)`，与聊天钩子开的自动朗读是两条入口，共用 Provider 选型。
