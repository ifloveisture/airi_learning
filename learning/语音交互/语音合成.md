# 语音合成

## 配置面

`packages/stage-ui/src/stores/modules/speech.ts`（`useSpeechStore`）：

- `activeSpeechProvider` / `activeSpeechModel` / `activeSpeechVoiceId`
- 可被角色卡覆盖 → [角色卡片](../角色对话/角色卡片.md)
- 手动试听：`speech(...)` → `@xsai/generate-speech`
- `speech-noop`：舞台 TTS 直接空返回（不发音）

设置页：`stage-pages/.../modules/speech.vue`。

## 提供商对照

| 类型 | 路径线索 | 说明 |
|------|----------|------|
| Official / 云端 | `libs/providers/.../official` · `official-provider-speech*` | 经 `apps/server` `/api/v1/openai/audio/speech`（及 speech WS），挂 Flux |
| 本地 Kokoro | `libs/inference/adapters/kokoro` · `workers/kokoro/` | 浏览器端侧合成（实验） |
| 其它厂 | providers 注册表 | ElevenLabs、Gemini speech 等辅助见 `stores/providers/` |

无云时优先本地 / BYO Key；Official 需登录与计费面。

## 聊天自动朗读

主挂点：`packages/stage-ui/src/components/scenes/Stage.vue`

1. `onBeforeMessageComposed` → 开 TTS session
2. `onTokenLiteral` → `appendText`
3. `onStreamEnd` / `onAssistantResponseEnd` 收尾
4. `createSpeechPipeline` + `speechRuntimeStore.registerHost`
5. `tts` 回调内 `getProviderInstance(activeSpeechProvider)` → `generateSpeech` 或双向 WS

相关：

- `stores/speech-runtime.ts` — intent（`openIntent`）
- `services/speech/pipeline-runtime.ts`
- 角色旁白：`stores/character` 的 `emitTextOutput`

口型接在播放后 → [视觉动捕](../舞台呈现/视觉动捕.md)。

## 阅读顺序

1. `speech.ts` 选型与试听
2. `Stage.vue` TTS session / token 钩子
3. `packages/pipelines-audio` 的 `createSpeechPipeline`
4. （可选）Official 路由 → [云端服务](../云端服务/)
