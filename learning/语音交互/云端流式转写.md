# 云端流式转写

## 定位

官方托管 **实时 ASR 代理**：`POST /api/v1/audio/transcriptions/stream`。当前上游实现含 Aliyun NLS；Stage 经 Official provider 调用。

## 真源

| 项 | 路径 |
|----|------|
| 路由 | `apps/server/src/routes/audio-transcription-stream/route.ts` |
| 挂载 | `apps/server/src/app.ts`（`/api/v1/audio/transcriptions/stream`） |
| Official provider | `packages/stage-ui/src/libs/providers/providers/official/index.ts` |
| Hearing 执行器 | `packages/stage-ui/src/stores/modules/hearing.ts`（`STREAM_TRANSCRIPTION_EXECUTORS` / `streamAliyunTranscription`） |

## 跟读

1. server 路由：鉴权、升级/流式响应形状
2. Official provider baseURL 如何指向该路由
3. `hearing` store：何时走 stream executor vs 本地/其它 STT
4. 对照非流式文件转写路径（其它 provider），避免混调

## 命令

```bash
pnpm -F @proj-airi/server dev
pnpm dev:web   # 或桌宠，用 Official 听力试
```

需有效登录/Official 配置与上游凭证（环境以 server 配置为准）。

## 现状

**已实现**（路由 + Official + Aliyun 流式 executor）。旧笔记若写「进行中」，以本页与源码为准。

## 边界

- **BYOK Aliyun**：客户端可直连自己的上游；与 Official **代理**是两套 executor。
- **VAD / TranscriptBuffer**：仍在端侧决定何时送出音频；本路由不管麦。
- **计费**：Official 路径可能走 Flux meter；细节见云端计费文档。
