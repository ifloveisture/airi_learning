# 听力转写

## 配置面

`packages/stage-ui/src/stores/modules/hearing.ts`（`useHearingStore`）保存 STT Provider / 模型等。

实际转写经 `useHearingSpeechInputPipeline`（或同名 composable 族）：

| API | 用途 |
|-----|------|
| `transcribeForMediaStream` | 流式 |
| `transcribeForRecording` | 录一段再转 |
| `stopStreamingTranscription` | 停流 |

设置页：`stage-pages/.../modules/hearing.vue`；对话框场景见 `scenarios/dialogs/audio-input/`。

## 两条产品路径

| 路径 | 场景 | 链路 |
|------|------|------|
| A. 流式 STT | Web `ChatArea` 等 | `stage-layouts/.../use-transcriptions.ts` → `transcribeForMediaStream` → `onSentenceEnd` 写入输入框 → 防抖自动 `ingest` |
| B. VAD + 录音 | 桌宠主舞台 / Hearing 测试 | `composables/audio/voice-input-session.ts`：VAD 起止 → 录段 → `transcribeForRecording` → `createTranscriptBuffer.flush` →（桌宠）`chatSyncStore.requestIngest` |

相关 composable：`audio-recorder` · `voice-input-vad-startup`；本地 Whisper 适配：`composables/whisper.ts`。

## VAD

| 符号 | 路径 |
|------|------|
| `useVAD` / VAD store | `packages/stage-ui/src/stores/ai/models/vad.ts`（`createVAD`） |
| Worker | `packages/stage-ui/src/workers/vad/`（`vad.ts` · `manager.ts` · `process.worklet.ts`） |

端侧说话检测，切段，少把静音送进 STT。
阈值（0.3 / 0.1 / 400ms / 250ms 等）→ [切段与播控](../算法主线/切段与播控.md)。

## 进聊天后

最终仍是 `useChatOrchestratorStore().ingest(text, { model, chatProvider })`。
关于 telemetry `sendSource` 是否标 `voice`：见 [聊天编排](../角色对话/聊天编排.md)（本地麦路径常**不**带 `options.input`）。

## 阅读顺序

1. `hearing.ts` + speech input pipeline
2. `voice-input-session.ts`
3. Web：`use-transcriptions.ts`；桌宠：`pages/index.vue` 语音送聊天段
4. [音频管线](./音频管线.md) 的 TranscriptBuffer
