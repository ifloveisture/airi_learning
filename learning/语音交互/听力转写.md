# 听力转写

## 定位

Hearing = **何时开麦 / 何时开始一句输入** + **STT 转写** + **句末判定 / 改写 / 可选说话人证据**。产品主路径走 `useVoiceStore`，不是旧的「只往输入框塞字再 ingest」。

## 配置面

`packages/stage-ui/src/stores/modules/hearing.ts`（`useHearingStore`）：

| 键 / 能力 | 作用 |
|-----------|------|
| `activeTranscriptionProvider` / model | STT Provider |
| `inputMode` | 见下表 |
| `autoSendEnabled` / `autoSendDelay` | 定稿后是否自动送出 |
| `endJudgeEnabled` | 句末判定：未说完则延长静音等待 |
| `rephraseEnabled` + provider/model | 转写后再用聊天模型改写（默认可开） |
| `speakerRecognitionEnabled` | 与声纹比分并 trace；**不**决定是否开麦 |
| `createTranscriber()` | 给 voice controller 的转写执行器 |

设置页（已拆目录）：

| 页 | 路径 |
|----|------|
| Hearing 总览 | `stage-pages/.../modules/hearing/index.vue`（入口卡 + `HearingConfig` 麦模式） |
| Transcriber | `.../hearing/transcriber.vue`（Provider / playground） |
| Wake words | `.../hearing/wake-words.vue` |
| Voiceprint | `.../hearing/voiceprint.vue` |

对话框组件：`scenarios/dialogs/audio-input/`（含 `HearingConfig` · `WakeWordStatus`）。

## 输入模式（`HearingInputMode`）

```ts
type HearingInputMode = 'always-on' | 'push-to-talk' | 'wake-word'
```

| 模式 | 麦是否常开 | 何时开始一句输入 |
|------|------------|------------------|
| `always-on` | 是（连续听） | VAD 检测到说话即可；唤醒词仍可切角色 |
| `push-to-talk` | 否（按住才开） | 按住 PTT 键期间 |
| `wake-word` | 是 | **仅**角色唤醒词；光说话不开输入 |

辅助：`listensContinuously(mode)` · `startsInputOnSpeech(mode)`（同文件）。PTT 触发：`composables/push-to-talk-trigger.ts` · `composables/voice-input-mode.ts`。

## 产品主路径（Voice 管线）

```text
麦 / 设备 store
  → useVoiceStore（plugins：VAD · 唤醒 · 句末 · 改写 · 说话人证据）
  → core-agent VoiceController + Hearing createTranscriber
  → 草稿 / inlay / 自动发送 → 聊天 ingest（可带 spoken-turn tools）
```

| 符号 | 路径 |
|------|------|
| `useVoiceStore` | `packages/stage-ui/src/stores/voice.ts` |
| VAD 插件 | `libs/voice/voice-activity-plugin.ts`（`cause`: `speech` \| `wake-word`） |
| 唤醒检测 | `stores/wake-word-detection.ts` · `stores/wake-words.ts` · `libs/voice/wake-words.ts` |
| 声纹 | `stores/voiceprint.ts` · 设置页 `voiceprint.vue` |
| 说话人 tracker | `stores/speaker-tracker.ts` · `libs/voice/speaker-evidence-plugin.ts` |
| 句末 / 改写 | `composables/voice-end-judge*` · `voice-rephrase*` |
| 输入 trace | `composables/voice-input-trace.ts`（唤醒 → 播放可跟 span） |
| UI | `voice-input-button.vue` · voice drafts / inlay |

Stage 宿主：`components/scenes/Stage.vue` 连接 `useVoiceStore`。

## 用户可见过程（读码前印象）

一次听入，产品侧大致经过这些态（名称是印象用，不是单一 enum）：

| 态 | 用户侧大致看到 | 背后在做什么 |
|----|----------------|--------------|
| 麦关 / 未开输入 | 麦按钮未进入听入；PTT 未按住 | 模式不允许，或尚未满足唤醒 |
| 听中 | 正在收声；VAD / 唤醒可能点亮 | Voice 开 input；切段后送 STT |
| 草稿 | 转写字出现在草稿 / inlay | `acceptSpeech`；`autoSend` 关则停在这里 |
| 自动送出 | 草稿短暂「发送中」后进聊天 | `autoSendEnabled` → `sendDraft` → chat `submit` / ingest |
| 已取消 | 听入或草稿消失 | `cancelInput` / discard；不进编排 |

常见中断（先查这里，再下钻源码）：

| 现象 | 先查 |
|------|------|
| 说话了但不进草稿 | `inputMode`（尤其 `wake-word`）；麦权限；VAD 是否切到段 |
| 有声纹分但不挡麦 | 预期行为：说话人识别只记分 / trace |
| 有草稿但不进聊天 | `autoSendEnabled` 是否关；发送失败时草稿会留下可再发 |
| 无 STT / Provider 未配 | Transcriber 设置；Web 可能还有浏览器 Speech 等回退策略 |
| 别窗抢走麦 | 桌宠多窗：另一窗持麦时本窗 input 会被 cancel |
