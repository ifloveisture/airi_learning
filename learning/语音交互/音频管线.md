# 音频管线

## 三个包

| 包 | 路径 | 职责 |
|----|------|------|
| `@proj-airi/audio` | `packages/audio` | 底层：WAV、AudioContext / worklet；无产品 UI |
| `@proj-airi/pipelines-audio` | `packages/pipelines-audio` | 编排：`createSpeechPipeline`、播放管理、TTS chunker、流控、`createTranscriptBuffer` |
| `@proj-airi/audio-pipelines-transcribe` | `packages/audio-pipelines-transcribe` | 转写辅助，如文件 → MediaStream |

产品模块（hearing/speech）应优先调 **pipelines-audio**，避免页面里手搓 AudioContext。
chunker / 优先级 / TranscriptBuffer 规则 → [切段与播控](../算法主线/切段与播控.md)。

## Workers（stage-ui 内）

| Worker | 路径 | 用途 |
|--------|------|------|
| VAD | `src/workers/vad/` | 端点检测；Web/Pocket 可能有副本入口 |
| Kokoro | `src/workers/kokoro/` | 本地 TTS（`kokoro-js`） |

## 最短闭环

| 目标 | 调用点 |
|------|--------|
| 听完一句话进聊天 | TranscriptBuffer + ingest（见听力） |
| 流式回复边说边播 | Stage.vue → SpeechPipeline → provider |
| 测文件当麦 | `audio-pipelines-transcribe` |

## 阅读顺序

1. `pipelines-audio` 导出 / README
2. Stage.vue、`voice-input-session` 调用点
3. 需要造测试流再看 `audio-pipelines-transcribe`
