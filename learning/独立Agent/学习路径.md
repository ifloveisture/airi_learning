# 学习路径 · 独立 Agent

面向「进程内自己跑 LLM loop」。Channel 桥请走 [通道机器人](../通道机器人/)。

## Phase 0 — 认路（必做）

读 [services全景](./services全景.md) + [对照总览](./对照总览.md)。

确认：`services/` 六个包里，**只有 Telegram / Satori 是本域主教材**；Discord 去通道机器人；Minecraft / Twitter / MCP 去世界接入。

## Phase 1 — Telegram（推荐先啃）

按 [Telegram专章](./Telegram专章.md)：

| 重点 | 为什么 |
|------|--------|
| 入队 → loop → dispatch | 同构骨架 |
| prompts + imagineAnAction | JSON 工具调用怎么「穷实现」 |
| read-message + pgvector | 独立记忆 |
| attention / interruption 注释 | 区分设计债与现网行为 |
| compose + OTel + db:push | 真能跑起来 |

```bash
pnpm i && pnpm run build:packages
cd services/telegram-bot && cp .env .env.local
docker compose up -d
cd ../..
pnpm -F @proj-airi/telegram-bot db:push
pnpm -F @proj-airi/telegram-bot start
```

## Phase 2 — Satori

按 [Satori专章](./Satori专章.md)：

| 重点 | 为什么 |
|------|--------|
| README temporary 边界 | 哪些会删、哪些会留 |
| IDENTIFY / READY / EVENT | 协议 Adapter |
| capabilities + constants | 轻量 loop 硬顶与 INTERRUPT |
| todolist 已完成项 | 并发/未读竞态课 |

需 Koishi `server-satori`：

```bash
cp services/satori-bot/.env services/satori-bot/.env.local
pnpm -F @proj-airi/satori-bot dev
```

QQ / Koishi 接不上时：先跟 [Koishi接入教程](./Koishi接入教程.md) 按里程碑验收；边界与误判 → [Koishi桥接坑点](./Koishi桥接坑点.md)。可先跟读 bot 源码，不必卡在扫码上线。
