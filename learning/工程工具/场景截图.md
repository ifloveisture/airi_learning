## Scenarios + Vishot

| 包 | 用途 |
|----|------|
| `packages/scenarios-stage-tamagotchi-browser` | 浏览器侧场景定义 / 产物 |
| `packages/scenarios-stage-tamagotchi-electron` | Electron 场景 |

```bash
pnpm capture:tamagotchi
```

经 `@vishot/cli`（及 `@vishot/*`）对桌宠入口截图；输出目录见根 `package.json` 脚本参数。
用于演示图与视觉回归，**不是**单元测试替代。

## Solutions / AI context

| 位置 | 用途 |
|------|------|
| `docs/solutions/` | 历史问题与修复（YAML：`module` / `tags` / `problem_type`） |
| `apps/server/docs/ai-context/` | 云端架构、路由、计费上下文 |
| `docs/ai/` | 更广协作上下文（如 `context/ui-components.md`） |

实现或排障前，可先按标签搜 `docs/solutions/` 是否已有同类坑。
检索字段、何时写新篇 → [Solutions用法](./Solutions用法.md)。
