# 性能探查

> 仓内**已有探查面**的入口图，不是性能调优手册，也不写指标基线专章。

## 定位

排「卡顿 / 掉帧 / 内存」时先开端上 Devtools，再决定是否加日志或 profiler。learning 不维护一份性能 ADR。

## 入口

| 端 | 路径 / 能力 |
|----|-------------|
| Web | `apps/stage-web/src/pages/devtools/performance-visualizer.vue`（FPS · frame · long task · memory 采样与导出） |
| Web 壳 | `App.vue` 可挂 `PerformanceOverlay`（`components/Devtools/PerformanceOverlay.vue`） |
| Pocket | `apps/stage-pocket/.../devtools/performance-playground.vue` |
| 桌宠 | 本端 `renderer/pages/devtools/`（以实际路由为准；部分 exclude 共享页） |

通用 Devtools 地图 → [Histoire与Devtools](./Histoire与Devtools.md)。

## 读码前印象

```text
设置 / Developer → Devtools → performance-*
  → 勾选指标 → 录一段 → 导出或看 overlay
```

| 指标面 | 说明 |
|--------|------|
| FPS / frame duration | 舞台与主线程节奏 |
| long task | 主线程长任务（浏览器支持因环境而异） |
| memory | 同样依赖浏览器暴露；不支持则页上有 unsupported 文案 |

## 跟读

1. Web：`pnpm dev:web` → Devtools → performance-visualizer
2. 需要浮层时看 `PerformanceOverlay` 与其 browser test
3. IO / 语音慢另走 skill `analyze-io-traces`（桌宠录迹），不在本页

## 边界

- **不是** CI 性能门禁说明（若有 workflow，见工程横切发布地图，不在此复写）。
- **不是** Live2D/Three 引擎内部 profiler 教程。
