# 角色卡片

## 两层概念

| 层 | 包 / 文件 | 做什么 |
|----|-----------|--------|
| 格式与导入导出 | `packages/ccc`（`@proj-airi/ccc`） | Character Card（含 CCv3）；JSON / PNG / MD / APNG |
| AIRI 业务绑定 | `packages/stage-ui/src/stores/modules/airi-card.ts` | 本地卡库、`activeCardId`、扩展字段灌模块 store |

ccc **不**实现 AIRI 模块逻辑；扩展在卡的 `extensions.airi`（`AiriExtension`）。

## `modules` 常见绑定

| 键 | 灌到哪 |
|----|--------|
| `consciousness.{provider,model}` | 意识 / 大脑 |
| `speech.{provider,model,voice_id,…}` | TTS |
| `vision.{provider,model}` | 视觉模块 |
| `artistry.*` | 生图 |
| `vrm` / `live2d` / `displayModelId` | 展示模型 |

## airi-card 行为

- `Map` 存多卡 + `activeCardId`
- `watchDebounced(activeCard)`：激活时写入 consciousness / speech / vision / artistry / display-models 等
- 反向：`updateActiveCardConsciousness` / `Speech` / `Vision` 等，设置页改模块时可写回卡

## UI

| 位置 | 路径 |
|------|------|
| 设置 | `packages/stage-pages/src/pages/settings/airi-card/`（含 Artistry 等 tab） |
| 场景组件 | `stage-ui` scenarios/settings 相关 |

## 和聊天的关系

发消息时「用哪颗大脑」只看 **consciousness store**；角色卡是**配置源**。切卡 = 切一整套模块默认，不是另起编排器。

## 阅读顺序

1. `packages/ccc` 导出与 Card 类型
2. `airi-card.ts` 的 watch 与 update*
3. `settings/airi-card/` UI
4. 对照 [模型提供商](./模型提供商.md) · [展示模型](../舞台呈现/展示模型.md)
