# 角色卡片

> Web / 桌宠共用同一套卡库（`stage-ui` + `stage-pages`）。Web 入口：设置 → Character Card；启动时 `apps/stage-web/src/App.vue` 会 `initialize()` 默认卡。

角色卡是**一整套角色默认配置的打包与切换源**，不是聊天编排器本身。发消息时「用哪颗大脑」只读 consciousness store；切卡 = 把卡上的模块默认灌进各模块 store。

## 真源

| 层 | 路径 | 做什么 |
|----|------|--------|
| 卡格式 / CCv3 | `packages/ccc`（`@proj-airi/ccc`） | `Card` 类型、JSON/PNG/MD/APNG 导出 |
| 业务绑定 | `packages/stage-ui/src/stores/modules/airi-card.ts` | 本地卡库、`activeCardId`、激活灌模块、拼 `systemPrompt` |
| ZIP 包 | `packages/stage-ui/src/services/airi-card-import-export.ts` | `airi-character-card` zip（`manifest.json` + `card.json` + 可选模型文件） |
| 设置 UI | `packages/stage-pages/src/pages/settings/airi-card/` | 列表 / 创建编辑 / 详情 / 导入导出 |
| 快捷切换 | `packages/stage-ui/src/components/misc/profile-switcher-popover.vue` | 聊天侧切 active 卡、复制卡 |

ccc **不**实现 AIRI 模块逻辑；产品扩展在 `extensions.airi`（`AiriExtension`）。

## 主要配置（两层）

### 1. 人设层（CCv3 / `Card`）

创建 / 编辑对话框五个 Tab 里，**Identity / Behavior / Settings** 对应这层。

| 字段 | 作用 | 创建时必填 |
|------|------|----------|
| `name` | 显示名（创建表单会 kebabcase） | ✓ |
| `nickname` | 昵称（CCv3） | |
| `description` | 角色描述，会进拼好的 system 上下文 | ✓ |
| `notes` | 创作者备注（给人看，不进对话拼装） | |
| `personality` | 性格与行为模式 | ✓ |
| `scenario` | 场景 / 背景设定 | ✓ |
| `greetings[]` | `[0]`=首句，其后=备选问候 | |
| `systemPrompt` | 核心系统指令 | ✓ |
| `postHistoryInstructions` | 历史后指令（保持人设） | |
| `version` | 卡版本号 | |
| `messageExample` / `tags` | 示例对话、标签（格式支持；UI 侧不如上列常用） | |

运行时拼装（`airi-card` 的 `systemPrompt` computed）：

```
systemPrompt + description + personality + artistry.widgetInstruction
```

空段会滤掉，用 `\n\n` 拼接。会话侧用这份结果生成初始消息等。

### 2. AIRI 模块层（`extensions.airi.modules`）

创建对话框的 **Modules / Artistry** Tab。激活卡时 `watchDebounced(activeCard)` 写入对应 store。

| 键 | 灌到哪 | 主要字段 |
|----|--------|----------|
| `consciousness` | 意识 / 聊天大脑 | `provider`, `model` |
| `speech` | TTS | `provider`, `model`, `voice_id`；可选 `pitch` / `rate` / `ssml` / `language` |
| `vision` | 视觉模块 | `provider`, `model` |
| `displayModelId` | 舞台展示模型 | display-models store 里的 id |
| `activeBackgroundId` | 该卡绑定的背景 | 详情里 Gallery 可选 |
| `vrm` / `live2d` | 旧式模型引用 | `source` + `file` \| `url`（现多用 `displayModelId`） |
| `artistry` | 生图 / 画廊挂件 | 见下表 |
| `agents.*` | 外部 Agent 提示（如 minecraft） | `{ prompt, enabled? }`；产品 TODO，未全面接 |

**Artistry 子配置：**

| 字段 | 含义 |
|------|------|
| `provider` / `model` | 生图提供商与模型 |
| `promptPrefix` | 提示前缀 |
| `widgetInstruction` | 挂件指令（进 system 拼装） |
| `spawnMode` | `bg` \| `widget` \| `inline` \| `bg_widget` |
| `options` | 提供商自定义 JSON |
| `autonomousEnabled` / `autonomousThreshold` / `autonomousTarget` | 自主生图开关、阈值、目标 |

缺扩展时：`resolveAiriExtension` 用**当前全局** consciousness / vision / speech / stageModel / artistry 填默认。

## 主要功能

| 功能 | 行为 | 入口 |
|------|------|------|
| 卡库持久化 | `localStorage`：`airi-cards` Map + `airi-card-active-id` | store |
| 默认卡 | 首次 `initialize()` 写入 `default`（ReLU + 系统 prompt） | Web `App.vue` onMounted |
| 新建 | `addCard(..., 'scratch')` | 设置页创建对话框 |
| 编辑 | `updateCard` | 创建对话框 edit 模式 |
| 复制 | profile switcher → `addCard(..., 'duplicate')` | 聊天侧弹出 |
| 删除 | `removeCard` | 列表 / 详情确认框 |
| 激活 | 设 `activeCardId` → debounce 灌各模块 store | 详情「Activate」/ profile switcher |
| 搜索排序 | 按 name/description 搜；nameAsc / nameDesc / recent | 设置列表页 |
| 导入 | ZIP → 校验 manifest + CCv3；可带入 display model | 设置页文件上传 |
| 导出 | 卡 JSON + 可选模型 → `.zip` | 详情「Export」 |
| 反向写回 | 设置页改意识/语音等可 `updateActiveCard*` | modules 设置页 |
| 会话隔离键 | `activeCardId` 参与 session 归属 | `session-store` |
| 背景 Journal | 按 `cardId` 存背景图；详情 Gallery 选 `activeBackgroundId` | `CardDetailDialog` |

**导入导出包形态：** `format: airi-character-card`，`card.json` 为 `chara_card_v3`；可选 `resources.displayModel`（Live2D zip / Spine zip / VRM）。导入只走白名单 schema，避免 zip 夹带额外字段。

## 和聊天的关系（边界）

| 是 | 不是 |
|----|------|
| 配置源：人设文案 + 模块默认 | 编排器 / FIFO / generation（在 chat orchestrator） |
| 切卡切换 Provider / 音色 / 舞台模型默认 | 长期记忆本体 |
| `systemPrompt` 拼装输入会话 | Provider 密钥与账号（在 providers store） |

## Web 跟读（从卡切入）

1. `pnpm dev:web` → 设置 → Character Card：列表 / 新建 / 导入
2. `airi-card.ts`：`AiriExtension`、`initialize`、`watchDebounced`、`systemPrompt`
3. `settings/airi-card/components/CardCreationDialog.vue`：五个 Tab 与校验
4. `airi-card-import-export.ts`：zip 契约
5. 激活一张卡后看 consciousness / speech / stage model 是否跟着变
6. 再读聊天编排：`stores/chat` → `ingest`（卡已灌进模块后再跟回合）
