# 对话工具

> 挂在 LLM 回合或角色卡上的**能力模块**，不是又一个聊天 store。

## Web Search（Tavily）

| 项 | 路径 / 事实 |
|----|-------------|
| 模块 store | `packages/stage-ui/src/stores/modules/web-search.ts` |
| 就绪条件 | `enabled` + `apiKey` → `configured` |
| 挂载 | `stores/llm-tool-resolver.ts` → `tools/web-search.ts` |
| 设置页 | `packages/stage-pages/.../modules/web-search.vue`（或同名路径） |

状态：可启用（需 Key）。解析进工具列表后由编排 / LLM tool-calling 路径消费。

## Artistry（生图）

> **先记住**：出图要接的是**图像生成后端**，不是聊天用的大语言模型（consciousness）。角色 LLM 只负责说话或按指令「想」出图；真正画图的是 Artistry 提供商。

### 定位

角色卡 / 全局模块里的图像生成能力：换背景、聊天内联图、浮层画布挂件。配置写在 `extensions.airi.modules.artistry`，激活卡时覆盖全局 Artistry 默认。

### 真源

| 项 | 路径 / 事实 |
|----|-------------|
| 模块 | `packages/stage-ui/src/stores/modules/artistry.ts` |
| 自主 | `artistry-autonomous.ts`（桌宠可走 IPC / headless） |
| 角色卡 | `extensions.airi.modules.artistry` |
| 创建 / 编辑 UI | `stage-pages/.../airi-card/components/tabs/CardCreationTabArtistry.vue` |
| 全局设置 | `stage-pages/.../artistry`（及各提供商页） |

### 要接入哪种「模型」

| 提供商 | 类型 | 说明 |
|--------|------|------|
| `none` | 关闭 | 全局 / 该卡跳过生图 |
| `comfyui` | **本地生图工作流** | 本机或局域网 ComfyUI；需先上传工作流模板 → 概念与跟读见 [ComfyUI 工作流](./ComfyUI工作流.md) |
| `replicate` | **云端文生图 API** | Replicate 上的图像模型（如 Flux 等）；需 API Key + 模型 ID |
| `nanobanana` | **云端图像预览** | Google AI Studio 向；偏预览 / 反应 |

**不要**把「接一个会聊天的 GPT / Claude」当成生图就绪条件。意识 Provider（OpenAI 兼容聊天模型）与 Artistry Provider 是并列模块：前者出文字，后者出图。

启用清单（缺一不可出图）：

1. Artistry 提供商 ≠ `none`
2. 对应后端可用（ComfyUI 服务 + 工作流，或 Replicate / Nano Banana 的 Key 与模型）
3. 角色卡 Artistry Tab（或全局）写好 `provider` / `model` 等覆盖项

### 卡级配置含义

| 字段 | 含义 |
|------|------|
| `autonomousEnabled` | 「电影式自主」：旁路「制片人」看对话，达阈值则自动生图 |
| `autonomousThreshold` | 0–100；越低越爱出图，越高越挑（默认约 70） |
| `provider` / `model` | 生图后端与模型（或 Comfy 工作流 ID） |
| `spawnMode` | 图放哪：`bg` 背景 · `inline` 聊天内联 · `widget` 浮层挂件 · `bg_widget` 双轨（默认） |
| `promptPrefix` | 拼在每次生图 prompt 前（画风 / 质量词） |
| `widgetInstruction` | 教角色 LLM「怎么用生图」的说明（会拼进 system） |
| `options` | 传给后端的 JSON（steps、分辨率、Comfy `template` 等） |

### 两条出图路径

1. **角色主动**：LLM 按 `widgetInstruction` 调 artistry 能力生图
2. **电影式自主**：`artistry-autonomous` 旁路打分 → ≥ 阈值 → 用卡上提供商 / 模型 / 前缀生图 → 按 `spawnMode` 投放

主路径**不是**与 `web_search` 同一条 `llm-tool-resolver` 表项；常以回合钩子 / 自主流程触发。

### 跟读

1. 设置 → Character Card → 新建 / 编辑 → Artistry Tab，对照上表点一遍
2. `artistry.ts`：全局 provider / model / Comfy 工作流持久化
3. （可选）`artistry-autonomous.ts`：`runArtistTask` → 阈值 → `spawnMode` 路由
4. 全局 Artistry / ComfyUI / Replicate 设置页各启用一次，确认 Key 与工作流；Comfy 专项见 [ComfyUI 工作流](./ComfyUI工作流.md)

### 现状

| 状态 | 说明 |
|------|------|
| 可启用 | 依赖外部生图后端；卡级覆盖 + 可选电影式自主 |
| 边界 | 聊天 LLM ≠ 生图模型；Provider 密钥在 providers / artistry 设置，不在卡明文里 |

## 对照

| | Web Search | Artistry |
|--|------------|----------|
| 典型触发 | LLM tool | 钩子 / 自主 / 卡配置 |
| 依赖 | Tavily Key | **生图后端**（ComfyUI / Replicate / Nano Banana） |
| 与 consciousness | 并列模块 | 并列模块（聊天模型不能代替） |

## 阅读顺序

1. `web-search.ts` + `llm-tool-resolver.ts`
2. `tools/web-search.ts`
3. `artistry.ts` +（可选）`artistry-autonomous.ts`
4. 设置页各点一次「启用」看持久化键
