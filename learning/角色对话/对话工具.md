# 对话工具

> 挂在 LLM 回合或角色卡上的**能力模块**，不是又一个聊天 store。

## Web Search（Tavily）

| 项 | 路径 / 事实 |
|----|-------------|
| 模块 store | `packages/stage-ui/src/stores/modules/web-search.ts` |
| 就绪条件 | `enabled` + `apiKey` → `configured` |
| 挂载 | `stores/llm-tool-resolver.ts` → `tools/web-search.ts` |
| 设置页 | `packages/stage-pages/.../modules/web-search.vue`（或同名路径） |

状态：可启用（需 Key）。解析进工具列表后由编排 / LLM tool-calling 路径消费。

## Artistry（生图）

| 项 | 路径 / 事实 |
|----|-------------|
| 模块 | `stores/modules/artistry.ts` |
| 自主 | `artistry-autonomous.ts`（桌宠可走 IPC / headless） |
| 角色卡 | `extensions.airi.modules.artistry` |
| 设置 | `stage-pages/.../artistry` · airi-card Artistry tab |

对接 ComfyUI / Replicate 等；**主路径不是**与 `web_search` 同一条 `llm-tool-resolver` 表项，常以回合钩子 / 自主流程触发。

## 对照

| | Web Search | Artistry |
|--|------------|----------|
| 典型触发 | LLM tool | 钩子 / 自主 / 卡配置 |
| 依赖 | Tavily Key | 外部生图后端 |
| 与 consciousness | 并列模块 | 并列模块 |

## 阅读顺序

1. `web-search.ts` + `llm-tool-resolver.ts`
2. `tools/web-search.ts`
3. `artistry.ts` +（可选）`artistry-autonomous.ts`
4. 设置页各点一次「启用」看持久化键
