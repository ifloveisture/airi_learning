# 模型提供商

## 两层：定义 vs 运行时

| 层 | 路径 | 职责 |
|----|------|------|
| 定义 / 注册表 | `packages/stage-ui/src/libs/providers/` | `defineProvider`、厂商 side-effect 注册、`listProviders`、校验 / onboarding 字段 |
| Pinia 运行时 | `packages/stage-ui/src/stores/providers.ts` | metadata、凭证、`initializeProvider`、`getProviderInstance`、模型/音色列表 |
| 辅助 | `stores/providers/` | converters、openai-compatible-builder、各 STT/TTS 专用辅助等 |

意识 / 语音 / 听力模块只存 **active provider id**（及 model / voice）；真正请求一律 `getProviderInstance(id)`。

## `getProviderInstance`（高层）

```text
查实例 cache
  → providerMetadata[id]
  → 读 credentials（requiresCredentials === false 可用默认）
  → metadata.createProvider(config)
  → 缓存并返回
```

## 意识模块

`stores/modules/consciousness.ts`（`useConsciousnessStore`）：

- 持久化大致：`settings/consciousness/active-provider` · `active-model`
- `configured = provider && model`
- 切 provider 时清空 model，防跨厂错模
- 设置页：`stage-pages/.../modules/consciousness.vue`

聊天编排从这里取「大脑」，再向 providers store 要实例。
