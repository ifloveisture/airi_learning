# 会话与云同步

> 本地会话真源是 **IndexedDB**；云同步是可选增强。
> 桌宠多窗 BroadcastChannel **不是**本页（见 [多窗同步](../多端应用/桌宠端/多窗同步.md)）。

## 本地

| 项 | 位置 |
|----|------|
| 持久化 | `session-store.ts` → `chatSessionsRepo`（IDB） |
| 能力 | 会话列表、消息、fork、清理 |

无登录、无 `apps/server` 也可完整本地聊。

## 云同步契约

| 层 | 路径 |
|----|------|
| 客户端库 | `packages/stage-ui/src/libs/chat-sync/`（`ws-client.ts` · `wire-message.ts` · `cloud-mapper.ts`） |
| Outbox | `session-store`：先入本地 outbox，再经 WS 推 |
| 契约包 | `packages/server-sdk-shared`（Eventa：`chat:send-messages` / `chat:pull-messages` / `chat:new-messages`） |
| 服务端 | `apps/server` → `GET /ws/chat?token=`（`routes/chat-ws/`）；跨实例常靠 Redis pub/sub |

```text
登录 Stage
  → chat-sync WS 连 /ws/chat?token=
  → 本地消息 → outbox → chat:send-messages
  → 其它端 chat:new-messages / pull
```

## 与两套「sync」对照

| 名称 | 传输 | 用途 |
|------|------|------|
| 本页云同步 | 云端 Chat WS | 跨设备 / 账号会话 |
| 桌宠 chat-sync | BroadcastChannel | 同机多 BrowserWindow |

## 阅读顺序

1. `libs/chat-sync/ws-client.ts`
2. `session-store` 里 outbox / push 相关
3. `server-sdk-shared` 事件名
4. 服务端挂载 → [云端服务/路由与能力](../云端服务/路由与能力.md)
