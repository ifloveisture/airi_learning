# 长期记忆边界

## 定位

「记忆」在仓内至少三处含义，**不要当成同一产品**：Stage 设置页 WIP、Telegram bot 向量检索、空壳包 `memory-pgvector`。

## 真源对照

| 面 | 路径 | 实际做什么 |
|----|------|------------|
| Stage UI | `packages/stage-pages/.../memory-short-term.vue` · `memory-long-term.vue` | 仅 `<WIP />` |
| Stage 上下文 | `packages/core-agent` context-registry + `stage-ui` session/IDB | **短期对话上下文**，非长期向量库 |
| Telegram | `services/telegram-bot/.../findRelevantMessages` 等 | embed + Postgres HNSW，检索 **chat_messages** |
| `memory-pgvector` | `packages/memory-pgvector/src/index.ts` | Channel Client 占位；`module:configure` 空；**无 pgvector 逻辑** |
| Satori | `services/satori-bot` session context | 进程内消息列表 + DB；**无向量检索** |

## 跟读

1. 打开 Stage 记忆设置页 → 确认 WIP
2. 读 `memory-pgvector/src/index.ts` → 确认空壳
3. （若关心 bot）Telegram `findRelevantMessages` / schema 中向量列
4. 日常 Stage 聊天：跟 `core-agent` + chat store 的上下文窗，而非本包

## 现状

| 项 | 状态 |
|----|------|
| Stage 长期记忆产品 | 进行中（UI 占位） |
| memory-pgvector | 进行中（进程占位） |
| Telegram 向量检索 | 可启用（bot 自有库） |

## 边界

- Telegram 记忆库 **不与** Stage IDB / 云 chat sync 共享。
- 算法向「余弦 + 时间衰减」规则写在算法主线的记忆检索笔记（针对 Telegram 实现）；Stage 尚未共用该实现。
- `memory_fragments*` 一类表若在 bot schema 出现但无业务读写，勿当成已上线功能。
