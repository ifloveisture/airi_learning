# 长期记忆边界

## 定位

「记忆」在仓内有多处含义，**不要当成同一产品**。Stage 本地长期记忆已可用；向量库与 bot 检索是另一条线。

## 真源对照

| 面 | 路径 | 实际做什么 |
|----|------|------------|
| Stage 长期记忆 store | `packages/stage-ui/src/stores/memory.ts` | `localStorage`：`enabled` + 按条目存事实；条目可挂角色卡（`persona`）或设为通用 |
| Stage 记忆工具 | `packages/stage-ui/src/tools/memory.ts` | `builtIn_readMemory` / `builtIn_writeMemory` / `builtIn_forgetMemory`；`composeMemoryPrompt` 把索引拼进 system |
| Stage 挂载 | `packages/stage-ui/src/stores/chat.ts` | 开启时把工具与索引 prompt 绑到当前角色卡回合 |
| Stage 设置 UI | `stage-pages/.../memory-long-term.vue` · `memory-long-term-memories.vue` | 总开关；按「通用 / 各卡」列出、删除条目 |
| Stage 设置（邻页） | `memory-long-term-recipes.vue` | **Recipes**（instructions / decision），不是记忆条目；同设置树入口 |
| Stage 短期页 | `memory-short-term.vue` | 仍为 `<WIP />` |
| Stage 会话上下文 | `core-agent` context-registry + session / IDB | **短期对话窗**，不是长期条目库 |
| Telegram | `services/telegram-bot/.../findRelevantMessages` 等 | embed + Postgres HNSW，检索 **chat_messages** |
| `memory-pgvector` | `packages/memory-pgvector/src/index.ts` | Channel Client 占位；`module:configure` 空；**无 pgvector 逻辑** |
| Satori | `services/satori-bot` session context | 进程内消息列表 + DB；**无向量检索** |

## 边界

- Stage 本地记忆 **不是** pgvector，也 **不** 与 Telegram 向量库、云 chat sync 共享。
- 会话 IDB / `core-agent` 上下文窗是短期回合上下文；长期事实走 `useMemoryStore` 条目。
- 算法主线「余弦 + 时间衰减」针对 Telegram 实现；Stage 本地记忆不用该公式。
- `memory_fragments*` 一类表若在 bot schema 出现但无业务读写，勿当成已上线功能。
- Recipes 存的是可复用指令 / 决策流，不是「一条事实」；记忆工具提示里也会写「不要把 recipe 已有内容再存成 memory」。
